- 시계 분침 드래그와 시침 기어 연동, 12시 순환, 시간 구간 렌즈, 정각/30분 퀴즈.
- 과일·색·모양 구슬 기차/팔찌, 최소 반복 마디 판정, 다음 구슬 제안, 동적 선택형 규칙 퀴즈, 100 수 배열판.

- 기존 분류 퀴즈의 중복 보상 차단과 격려 피드백. 신규 활동은 공통 음성 엔진을 호출하며 자체 API나 운영 DB 시험 기록을 만들지 않는다.

- `node scripts/verify_math_phase1.cjs`: 390×844 모바일 및 1280×900 PC Chrome에서 64개 판정 통과, pageerror 0, 로컬 리소스 404 0.
- 실제 브라우저 입력: 분침 정방향/역방향 한 바퀴, Chrome 터치 이벤트 반 바퀴, ±30분, 퀴즈 선택·재클릭, 구슬 조립/삭제, 반복 분석, 팔찌 전환, 수 배열 답 선택, 기존 조립 3단계와 재시작, 도장 잉크 선행 조건·3종 면 찍기, 조각 추가·방향키 이동·회전·삭제, 3종 밑그림.
- 시계 음성 읽기·정답 칭찬 호출을 스파이로 확인하고 재클릭 시 칭찬이 중복 실행되지 않음을 검사.
- 정적 검사: 변경 활동 파일 8개에 `scripts/verify_contracts.py --mode file --file ...` 모두 `[ALL PASS]`. 신규 JS 5개 `node --check` 통과. `git diff --check` 통과.
- `scripts/ai_verify.py .../clock_rules_logic.js --mode verify`: `✅ [통과] 이상 없음` 응답.
- 총 6개 모바일/PC 스크린샷을 직접 열어 도화지·시계·구슬·안내문의 배치를 확인. 문서 전체 가로 넘침 없음. 모양 탭 목록은 기존의 의도된 가로 스크롤 방식.

## 제한과 구분

- 외부 요청을 모의 응답으로 대체한 브라우저 검사이므로 운영 Notion/음성 서버 연결 성공이나 실제 휴대폰 음질·재생 성공을 뜻하지 않는다. 실제 음성 청취는 미검증이다.
- 추가 `shapes_stamp.js` Gemini 코드 전송은 자동 승인 검토가 외부 소스 전송 승인 근거 부족으로 거절했다. 해당 검증은 실행하지 않았으며 로컬 동작·구문·계약 검사 결과로 구분한다.
- 기존 인계서의 782줄과 달리 실제 시작 파일은 1,632줄이었다. 조립 완료 버튼은 이미 별도 `renderWorkshopSVG()`에 있었으며 삭제·재구현하지 않았다.
- 교과서 원문 전체 대신 사용자 인계 명세를 구현 근거로 사용했다.
