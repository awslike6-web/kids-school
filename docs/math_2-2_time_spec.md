## 2. 교과 범위

- 몇 시 몇 분 읽기(5분 단위 → 1분 단위), 시계에 나타내기, 몇 시 몇 분 전, 1시간 = 60분(몇 시간 몇 분 ↔ 몇 분), 걸린 시간(시간 띠), 하루 = 24시간·오전과 오후·1일 몇 시간 = 몇 시간, 1주일 = 7일·달력 보기·달마다 날수.
- **시각은 1시~12시**(12시간제, 「0시」·「13시」 없음). 분은 0~59. 시각 글 `fmtTime(h, m)`: `3시`·`3시 25분`·`12시 5분`. 시간 글 `fmtDur(min)`: `40분`·`1시간`·`1시간 20분`.
- 걸린 시간은 **한나절 안**(끝 시각이 12시 정각 이하, `eh*60+em ≤ 720`)·**20~90분**만 시계 시각으로 묻고 시간 띠 그림을 같이 보여 준다. 오전 → 오후를 넘는 것은 4관 하루 시간 띠로 「몇 시간」만 묻는다. 분 ↔ 시간 바꾸기는 70~150분(100·120 빼고).
- 소리: Korean TTS는 `3시 25분`을 「세 시 이십오 분」, `1시간 20분`을 「한 시간 이십 분」으로 읽는다(폰 확인 몫). 화면 글을 그대로 읽되 **이모지는 읽는 글에서 뺀다**(동물은 이름만, 이모지는 따로 배지). `fact`가 있는 문제는 `speak = fact + 공백 + question`(계산 모듈이 만든다). 숫자 뒤 조사는 받침에 맞춘다(`7을`·`5를`·`11을`·`12를`, 계산 모듈 안 작은 표).

### 3-1. 시계 그림 부품 `ClockDraw` (`js/time_clock-draw.js`, 새 파일)

- `clock({ h, m, step, draggable, onChange, hourHint, hideHour })` → `{ el, set(h, m), get() → { h, m }, lock(bool) }`.
  - SVG `viewBox 0 0 200 200`, 화면 폭 `100%`·최대 240px(360px 화면에서 가로 넘침 없음). 1~12 숫자(16px 이상으로 보이게), 분 눈금 60개(5분마다 굵게), 짧은바늘(굵고 짧게, 색 A)·긴바늘(가늘고 길게, 색 B), 가운데 핀.
  - **시침은 분에 따라 이어서 움직인다**: 시침 각 = `(h % 12) * 30 + m * 0.5`, 분침 각 = `m * 6`.
  - `draggable: true`면 **긴바늘을 손가락으로 끌어 돌린다**(포인터 이벤트, `touch-action: none`, `setPointerCapture`로 손가락이 시계 밖 여백으로 나가도 계속 따라감 — 손가락이 눈금을 가리지 않게). 각도 → 분, `step`(1 또는 5)에 맞춰 반올림. **시는 바뀌지 않는다**(맞추기 활동은 모두 목표 시의 정각에서 시작하므로 분만 맞춤; 12를 지나가도 시 그대로, 짧은바늘은 `h + m/60` 위치로만 움직임). 판 어디를 눌러도 긴바늘이 그쪽으로. 바뀔 때마다 `onChange({h, m})`. 지금 긴바늘이 가리키는 분 눈금 하나를 굵고 밝게 칠한다(숫자 시각은 보여 주지 않음 — 정답을 미리 보이지 않게).
  - `hideHour: true`면 짧은바늘을 숨긴다(1관 ①).
  - `hourHint: true`면 짧은바늘이 있는 두 숫자 사이 부채꼴을 옅게 칠한다(1관 계단용).
- `timeBar({ start, end })` — **시간 띠**: 시작 시의 정각부터 끝 시의 다음 정각까지(최대 3시간 폭, 분 단위 하루 시각, 예 130 = 2시 10분), 1시간마다 큰 칸·10분마다 작은 칸, `start`~`end`를 색칠, 위에 정각 숫자(`2시`·`3시`…). 폭 100%(최대 340px), 높이 90px 이내. 3관 걸린 시간용.
- `dayBar({ start, end })` — **하루 시간 띠**: 0~24시 24칸(오전·오후 띠 색 다름), 숫자는 **3시간마다만**(`12 3 6 9 12 3 6 9 12`), 가운데 「낮 12시」, 시작·끝 칸 위에 그 시각 숫자를 크게 따로 표시, `start`~`end`(시 단위 0~24)를 색칠. 4관용.
- `calendar({ firstDay, days, mark })` — **달력**: 일~토 7열(일요일 빨강·토요일 파랑 글자), `firstDay`(0=일)부터 1~`days`일, `mark`(날짜 배열)는 동그라미. 보는 그림이라 누르는 칸 크기 제한 없음: 폭 100%(최대 340px)를 7등분, 글자 14px 이상.
- 읽기 문제(`read5`·`read1`·`before` 가)의 시계는 두 바늘이 20° 이상 떨어진 시각만 낸다(`TimeClockCore.handsApart`, 4시 22분처럼 겹치면 읽기 어려움 — 화면 확인에서 찾음).
- 순수 함수(시험 대상, DOM 없이): `handAngles(h, m)` → `{ hour, minute }`, `angleToMinute(deg, step)`(0~59, 60이 되면 0).

- **오개념** (힌트 20자 안팎): `number-as-minute`(긴바늘 숫자를 그대로 분), `next-number`(이웃 숫자), `hand-swap`(긴바늘·짧은바늘을 바꿔 읽음), `count-back`(다음 숫자에서 거꾸로 세다 틀림), `minus-one`, `ten-year`, `day-confuse`, `month-mix`, `before-as-minute`, `off-five`, `before-hour`, `before-ignore`, `hundred-hour`(1시간을 100분으로), `hour-as-one`, `hundred-split`, `digit-split`, `ten-off`, `hours-only`(분을 빼먹음), `ampm-swap`, `wrong-scene`, `ten-day`(하루를 10시간으로), `day-as-one`, `pm-raw`(오후 시각을 그대로 뺌), `off-one`, `ten-week`, `school-week`(1주일을 5일로), `plus-one`(1주일 뒤를 다음 날로).

## 5. 순수 계산 모듈 `TimeClockCore` (`js/time_clock-core.js`, DOM 없음, 시험 대상)

- `randInt`, `fmtTime(h, m)`, `fmtDur(min)`, `addMinutes(h, m, d)`(1~12시 순환), `josaNum(n, kind)`(숫자 받침에 맞는 조사, kind `을`·`이`·`와`), `WEEKDAYS`(일~토), `MONTH_DAYS`(1~12월, 2월 28), `SCENES`(4관 장면 표), `FRIENDS`(6관 동물: 토끼·곰·여우·다람쥐·고양이, 이모지·이름·와/과).
- `makeProblem(kind, rng)` → `{ kind, question, fact, speak, answerText, …종류별 값 }`(`speak` = fact가 있으면 fact + ' ' + question, 이모지 없음). 종류별 값: `min-of-number {n}` · `read5|read1|set5|set1 {h, m}` · `before {dir: 'to'|'from', h, m}`('to' = (가) 시계 h:m, 'from' = (나) h시 정각과 몇 분 전 m) · `h-to-min {h, m}` · `min-to-h {min}` · `elapsed {sh, sm, eh, em, dur}` · `am-pm {scene}` · `day-hours {d, hr}` · `day-elapsed {start, end}`(0~24시) · `week-days {n}` · `cal-week {firstDay, days, date, dir: 'after'|'before'|'same'}` · `month-days {month}`(0이면 1년 = 12개월 문제).
- 4관 `am-pm` 장면 표: 아침밥 먹기 오전 7시 · 학교 가기 오전 8시 30분 · 수업 듣기 오전 10시 · 학교 끝나기 오후 1시 · 간식 먹기 오후 3시 · 저녁밥 먹기 오후 6시 · 잠자기 오후 9시(낮 12시 근처 장면은 넣지 않음). 질문은 장면마다 손으로 적는다(「잠자는 시각으로 알맞은 것은?」 등, 25자 이내).
- `wrongChoices(p)` → `[{ text, mistake }]` 정확히 2개, 정답·서로와 **글자도 값도** 다름(시간 길이는 분 값으로 비교: 「60분」과 「1시간」은 같은 값), 시각은 1~12시·0~59분, 시간·분은 양수(「0분 전」·「0시간」 없음), 분 부분은 0~59(「1시간 60분」 없음). 모자라면 ±5분·±10분·±1(단위 그대로)로 채움.
- `LAB_KINDS`: 1관 `min-of-number, read5, set5` · 2관 `read1, set1, before` · 3관 `h-to-min, min-to-h, elapsed` · 4관 `am-pm, day-hours, day-elapsed` · 5관 `week-days, cal-week, month-days`. `makeRound(lab, rng)`(한 판 3문제, 중복 없음).
- `BINGO_KINDS` = `h-to-min, min-to-h, before, day-hours, week-days`, `makeBingo(rng)` → 9문제(답 글자·값 모두 서로 다름·7자 이하, 각 문제 `call`과 `speak`: 「1시간 20분은 몇 분?」·「90분은 몇 시간 몇 분?」·「3시 10분 전은 몇 시 몇 분?」·「1일 6시간은 몇 시간?」·「2주일은 며칠?」, `before`는 (나) 방향만).
- `makePromise(rng)` → `{ name, emoji, h, m, text, speak }`(6관, 분은 절반 5~55의 5의 배수·절반 1~59의 5의 배수 아닌 수, `text` 「토끼와 4시 35분에 만나요!」), `setFeedback(curM, targetM)` → `{ ok, diff, text }`(같은 시 안이라 diff = 목표 분 − 지금 분, 「5분 더 돌려요」·「3분 덜 돌려요」).

## 9. 설계 검토 기록 (2026-11-26)

카본(medium)·네온(medium)에게 같은 초안을 동시에 보냄(아이 이름 가림). 카본 15건·네온 14건, 겹친 것이 많아 29건 모두 반영.
- 끌기 시계가 12를 지나면 시가 바뀌어(첫 터치에도) 안내·분 차이가 틀어짐 → 맞추기 활동은 모두 목표 시 정각에서 시작하고 **시를 고정**, 차이는 같은 시 안 분 차이.
- 보기만 보고 찍는 틈: 시각 읽기 보기가 「정답 / 분만 다름 / 시만 다름」이면 다수결로 정답 → `hand-swap`(시·분 둘 다 다름)으로 바꿈, 오전·오후 셋째 보기도 반대쪽·다른 시로, 분 → 시간 오답 모양 맞춤.
- 오답이 정답과 같아짐: `pm-raw`(시작 − 끝 = 6 쌍 제외), `hours-only`(정각을 꼭 한 번 넘고 60분 제외), `off-five` 0분 전, `hundred-split` 1시간 60분(150분까지), `count-back` 공식(up + (up − m), m ≤ 54), 1관 10배 오답(분 범위 밖 → 이웃 숫자).
- 빙고에 같은 값 다른 표기(80분·1시간 20분) → 값도 다르게, 배우지 않은 `later` 빼고 `week-days`, 칸 두 줄 허용.
- 2학년 범위: 분 ↔ 시간 150분까지·걸린 시간 20~90분·시간 띠 최대 3시간, 「오후 12시 30분」 장면 뺌, 2월·「1년 = 12개월」 넣음(28일이 늘 틀린 보기가 되지 않게), 주먹 셈법은 `why`에 먼저 설명.
- 화면: 하루 띠 숫자 3시간마다, 달력 7등분(44px 제한은 누르는 버튼에만), 시계 끌기 포인터 캡처·지금 분 눈금 강조, 몇 분 전 문제에 시계 그림, 달력 문제에 1주일 전·같은 요일 변형.
- 소리: 이모지는 읽지 않음, fact + question 이어 읽기, 숫자·동물 뒤 조사 맞춤.
