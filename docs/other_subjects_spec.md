# 기타 과목(도덕·미술·보건 등) 등록 명세 v0.1

> 2026-11-17 초안 (Claude). 주 과목(국어·수학·영어·사회·과학) 밖의 교과를 공부방에 넣는 규칙.
> 관련: [`notion_schemas_school.md`](notion_schemas_school.md) VOCA_DB, [`video_unit_spec.md`](video_unit_spec.md) 단원 영상.

## 1. 원칙
- **핵심 개념 낱말만** 넣는다. 과목방·퀘스트·실험실은 만들지 않는다(인지 부하, GEMINI.md §2).
- **교과서 사진이 있는 과목부터.** 원본 사진: `H:\내 드라이브\공부\공부자료\{학생}\{학년}\{과목}\` (스마트폰 촬영, EXIF 정방향 보정 후 읽기).
- 낱말 출처는 교과서의 **찾아보기(용어 색인) → 단원 정리 쪽 → 본문** 순으로 찾는다. 상세설명에 교과서 쪽수를 적는다.
- 뜻풀이를 교과서에서 그대로 옮기지 못한 경우(색인에는 낱말·쪽만 있음) 초등 눈높이로 새로 쓰고, 자료 `_설명`에 그렇게 적는다.

## 2. 노션 계약 (VOCA_DB)
| 칸 | 값 |
| :--- | :--- |
| 과목 | 교과서 과목명 그대로: `도덕`, `미술`, `보건`, `음악`, `체육`, `실과` |
| 학년 | 학기별 책이면 `5-2`처럼 하나. **1년짜리 책**(도덕 5·미술 5·생활 속의 보건 5)은 학기를 단정하지 않고 `["5-1", "5-2"]` |
| 단원 | 교과서 차례 표기 그대로 `{번호}. {단원명}` (예: `4. 건강 안전과 응급 처치`) |
| 학생 | 그 교과서를 쓰는 아이 (`민수`) |
| 어휘유형 | `개념` |

- 등록 도구: `scripts/register_voca.py` + 자료 `scripts/data/voca/{과목영문}_{학년}_u{단원}.json` (예: `health_5_u4.json`). 단원별 스크립트 금지.
- 새 과목 첫 등록 때 노션은 아직 없는 선택지로 거르면 400을 낸다. 등록기는 이를 "기존 행 0개"로 본다(2026-11-17).

## 3. 아이에게 보이는 곳
- **v1 = 용어사전방**(`kids/common_space/voca.html`). 과목·학년·단원 필터를 데이터에서 만들므로 코드 수정 없이 `📘 보건` 같은 칩이 생긴다.
- 퀘스트·과목방·부모 진도판은 과목으로 걸러 읽어서 새 과목 행이 섞이지 않는다(2026-11-17 확인: `fetchVocaFromNotion` 호출부는 모두 `subject` 지정, 용어사전방만 전체).
- 다음 판 후보: 단원 영상(`video-unit.js`)을 기타 과목 단원에도 붙이기, 5분 퀘스트에 "교양 한 문제" 넣기.

## 4. 주의
- **용어사전방은 기본으로 모든 학생 낱말을 함께 보여 준다.** 사춘기·생식기처럼 동생(초1)에게 이른 단원(보건 3단원 「성과 건강」)은 부모 결정 전까지 등록하지 않는다.
- 노션에서 직접 고친 뜻풀이는 등록기 `--apply`로 덮어쓰지 않는다(`--update`일 때만 덮어씀).
