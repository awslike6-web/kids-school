# 클래스카드 연습 카드 노션 이관 검증 기록 (2026-11-28)

## 바뀐 것

- 카드 묶음 원본을 하드코딩 파일 `kids/subjects/english/data/classcard_5-2_L11.js`에서 노션 「🃏 클래스카드 DB」로 옮겼다. 옛 파일은 지웠다. 노션 DB는 사용자가 빈 표를 만들었고, Claude가 프록시로 열 10개를 채웠다.
- 화면 `classcard.html`은 `kids/js/english_classcard_deck.js`(`EnglishClasscard.Deck.load`)로 노션을 새로 읽는다. 「사용」이 켜진 카드만 보이고, 빈 구간은 숨는다. 통신이 안 되면 기기에 기억한 마지막 묶음으로 연다.
- 영어방 「이번 단원 특별 활동」의 🃏 칸은 등록표 없이 노션 단원 목록(`Deck.listUnits`)으로 뜬다.
- 공식 등록 도구 `scripts/register_classcard.py`와 자료 `scripts/data/classcard/english_5-2_L11.json`을 만들었다. 노션에 44장을 등록했다.
  - 1~34번: 옛 파일과 같은 카드번호·글자이고 사용은 켰다.
  - 35~44번: 4구간 새 문장 10개이고 사용은 껐다.
- 노션에서 끈 카드의 별표는 `state.hiddenBookmarks`로 남겨 둔다. 다시 켜면 돌아온다.

## 브라우저 검증 (쓰기 차단 서버 `guarded_preview_server.py` 8767, 폰 375×812)

- 민수 `classcard.html?grade=5-2&unit=L11`: 제목 「5-2 Lesson 11」, 「담임 클래스카드 · 총 34개」, 구간 「전체(34) · 1구간(10) · 2구간(10) · 3구간(14)」이 나왔고 4구간은 보이지 않았다. 기기 기억 키 `classcard_deck_v1_son_5-2_L11`이 생겼다(노션 조회가 성공했을 때만 저장됨).
- 등록 도구 `--set-use off --cards 1`로 노션 1번(bank)을 끄고 다시 열었다. 「총 33개」, 「1구간(9)」이 나왔다. 그 뒤 `--set-use on --cards 1`로 되돌렸고, 다시 읽어 사용 켜짐 34장(1~34번) / 전체 44장임을 확인했다.
- 1단계 매칭: 2×4 판이 노션 카드로 그려졌다. festival ↔ [명] 축제를 맞히자 점수 50, 「50 / 1,500」이 됐다.
- 영어방: 5-2 · 11단원을 고르면 「⭐ 이번 단원 특별 활동」에 「마을 길 찾기」와 「클래스카드 연습」이 나온다. 「클래스카드 연습」을 누르면 `classcard.html?grade=5-2&unit=L11`이 열리고 34개가 나온다.
- 민서 프로필(5학년 미리보기 끔): 「준비 중인 단원이에요」가 나온다(승인받은 동작). 처음에는 제목 아래 「카드를 불러오는 중…」이 남아 있었는데, 고친 뒤 비는 것을 사진으로 확인했다.
- 가로 넘침 없음(scrollWidth 375 = innerWidth 375). 콘솔 오류 0.

- 화면: 지적 8건 중 3건을 반영했다. 수정본 초안은 하이드로젠이 썼다.
  - 단원 목록이 묶음과 같은 기준을 쓰도록 함
