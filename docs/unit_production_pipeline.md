# 🚀 [SSOT] 공부방 단원 콘텐츠 제작 및 대화창 인계 공식 가이드 (unit_production_pipeline.md)

> **문서 목적**: 새 대화창(세션)을 개설하거나 다른 에이전트가 단원 제작 작업을 이어받을 때, 단 1%의 누락이나 기억 왜곡 없이 100% 동일한 표준으로 교과 콘텐츠를 조립·배포할 수 있도록 규정한 **단일 원천(SSOT) 인계 명세서**.

---

## 1. 3단계 제로-크레딧(Zero-Credit) 단원 제작 파이프라인

교과서 사진을 직접 안티그래비티 대화창에 대량 업로드하면 불필요한 이미지 토큰이 소모됩니다.
반드시 아래 **3단계 분업 파이프라인**을 준수합니다.

```mermaid
flowchart LR
    A["1단계: 교과서 사진 무료 투입<br>(Google NotebookLM)"]
    -->|"크레딧 0원 무료 추출"| B["2단계: 순수 텍스트 결과 복사<br>(용어, 뜻, 퀴즈, 시나리오)"]
    -->|"텍스트만 대화창에 전달"| C["3단계: 안티그래비티 자동화<br>(5분퀘스트 + 스토리북 + 노션)"]
    --> D["결과: 표준 모듈 1초 깃 배포 🚀"]
```

### [1단계] 부모님의 노트북LM 추출 프롬프트 표준
노트북LM에 교과서 사진(JPG/PDF)을 무료로 올리고, 아래 프롬프트를 복사하여 질문합니다:
> *"이 교과서 내용에서 다음 3가지를 정리해줘:*  
> *1) 핵심 어휘 5개 (단어, 뜻풀이, 초성힌트)*  
> *2) 5분 퀘스트용 4지선다 퀴즈 3문제 (질문, 4개 선택지, 정답, 1줄 해설)*  
> *3) 초등학생 눈높이의 흥미진진한 8장면 단원 동화 줄거리 (각 장면별 상황 묘사와 대화문)*"

## 2. 5분 퀘스트 & 노션 연동 규격 (최신 V3 하이브리드 아키텍처)

### 1) 4+1 듀오링고형 출제 구조
* **1~3번 [학교 진도 집중 드릴]**: 현재 단원 핵심 드릴 (정적 문제 + 노션 어휘 + 노션 교재·사료 퀴즈 실시간 자동 융합)
  - 🧮 **수학 특화 (답 외우기 차단 무한 난수 암산)**: 정적 4지선다 답 암기를 방지하기 위해 나눗셈/분수의 곱셈 등 핵심 연산은 `generateDynamicMentalMath`로 출제.
  - 📝 **손글씨 계산 연습장**: 상단 `[📝 계산 메모]` 클릭 시 캔버스 드로잉 모달(`mathMemoModal`) 지원.
  - 🔍 **사료/실험 사진 고화질 돋보기**: 사진 터치 시 전체 화면 확대 모달(`imageZoomModal`) 지원.
* **4번 [망각곡선 자동 복습]**: 라이트너 3상자 간격 반복 큐 자동 소환 (3회 연속 정답 시 졸업)
* **5번 [🎁 다음 단원 비밀 맛보기]**: 다음 단원 맛보기 탐험 (틀려도 하트 0개 차감, 맞히면 경험치 2배)

### 2) 노션 용어사전(VOCA DB) 자동 합성 원칙
* **저장 위치**: 노션 VOCA DB (`375a27115b688038b686d3994ee12919`)
* **핵심 필드**: `단어`(title), `뜻풀이`(rich_text), `초성힌트`(rich_text), `과목`(multi_select), `학생`(multi_select), `단원`(rich_text/number), `이미지파일`(files/url), `인터랙티브 링크`(url)
* **엔진 동작**: `quest_notion_synth.js`의 `buildVocaQuestionsFromNotion`이 당일 로컬 캐시(`MINMIN_VOCA_CACHE_V11_`)를 읽어 런타임에 4지선다 문제를 실시간 자동 조립함 (코드 수정 불필요).
* **안티그래비티 자동화**: 부모님이 노트북LM 추출 텍스트를 대화창에 전달하면, 내부 파이썬 스크립트(`scripts/sync_*_voca_notion.py`) 또는 노션 API를 통해 안티그래비티가 VOCA DB에 원클릭으로 일괄 자동 전송.
* **철벽 학년 가드**: `source === 'notion_voca'` 속성을 부여하여 초1 민서와 초5 민수의 어휘가 절대 섞이지 않도록 완전 격리.

### 3) 노션 교재·사료 마스터 DB 연동 및 퀵체인지 2.0 원칙
* **저장 위치**: 노션 교재·사료 마스터 DB (`3e8a27115b68806d94bfc81e9b3435fa`)
* **역할 및 용도**: 사회 역사 유물/지도, 과학 실험/관찰 사진 자료 및 관련 4지선다 퀴즈 저장.

## 3. 신규 단원 스토리북 표준 제작 프로토콜 (규칙 9 준수)

1. **이미지 배치**:

   * PC 책넘김용 양면 펼침면: `(2200x1700)` 해상도 (`create_*_spreads.py` 파이프라인 활용)
   * 모바일 웹툰용 단일 삽화: `(1100x1700)` 해상도
2. **도서 데이터 모듈 생성**:
   * 경로: `kids/subjects/{과목}/data/story_{식별자}.js`
   * 구조: `window.STORY_BOOK = { id, title, icon, themeColor, backUrl, pages: [...] };`
3. **초경량 래퍼 HTML 생성 (단 75줄)**:
   * 경로: `kids/subjects/{과목}/{식별자}_storybook.html`

## 4-1. 🔬 과학 단원 특화: 5대 가상 실험실 & NotebookLM 실험연계 디지털 탐구 보고서 표준 (`science-unit-builder`)

과학 단원(예: 5-2 3단원 『열과 우리 생활』, 4단원 『물체의 운동』, 5단원 『산과 염기』 등)을 제작하거나 개선할 때는 **스킬 `science-unit-builder`(`kids-school-main/.agent/skills/science-unit-builder/SKILL.md`)**를 필수 호출하며 아래 3대 원칙을 100% 강제 적용합니다:

1. **🚫 단순 용어 맞추기형 탐구 보고서 퇴행 금지**:
   - `[4단계] 탐구 보고서`는 `[2단계] 용어방`과 역할이 완전히 다릅니다. 정의 문장에 단어 3개만 끼워 넣는 빈칸 문제나, 이미 정렬된 순서 확인 버튼을 절대 만들지 않습니다.
2. **📑 `window.SCIENCE_LAB_REPORT_{N}_DATA` 4대 필수 구성 (N단원 플러그앤플레이)**:
   - `science_report.js`는 `SCIENCE_LAB_REPORT_{N}_DATA`를 자동 인식하므로 엔진 코드 수정 없이 데이터 객체만 추가하면 작동합니다:
     - **① `conceptTables` (비교표 2~3종)**: 실험 기구 특징·쓰임새 비교표, 조건별 변화 방향표, 원리별 1:1 실생활 적용 사례표.
     - **② `summaryDoc` (교과서 4~5대 실험 상세 분석)**: 실험별 준비물·단계별 과정, **반응형 인라인 SVG 그래프(`diagramHtml`)**, 관찰 결과, 결론, 생각해 볼까요, **`labLink`(가상실험실 바로가기 버튼)**, **`safetyTip`(안전 수칙 배지)**.
     - **③ `specialDeepDive` (첨단 과학 심화 탐구 박스)**: 교과서 원리가 적용된 첨단 과학 스토리(예: KSTAR 인공 태양 1억 ℃ 단열 비밀).
     - **④ `quizItems` (참여형 실험 탐구 & 서술형 미션 6종)**:
       - `q1` (`blank` 서술형 빌더 1): 실험 그래프/결과 해석 서술형 (`rubric` 채점기준 30%/30%/40% + `templateHtml` + 4~5개 과학 구절 블록 조립)
       - `q2` (`choice` 실험 추론): 대조군/실험군 조건 변화 추론 4지선다
       - `q3` (`order` 실험 순서 직접 조립): 무작위 섞인 4단계 실험 과정 카드를 터치해 1~4단계로 직접 배열
       - `q4` (`choice` 실험 기구 & 오개념 판별): 실험 기구 쓰임새 및 대표 오개념 찾기 4지선다
       - `q5` (`blank` 서술형 빌더 2): 실생활 적용 & 심화 탐구 원리 서술형 (`rubric` + 구절 블록 조립)
       - `q6` (`self_check` 배움 확인 체크리스트): 5~6개 성취기준 인터랙티브 ⭐ 별점(1~3개) 평가 (+5💎)
3. **🔍 원클릭 자동 검증**:
   - 작업 완료 후 반드시 `python -X utf8 scripts/verify_science_unit.py --unit {N}`을 실행하여 골디락스 줄 수(`< 800줄`), 모달 초기화 가드, 서술형 빌더 슬롯 정합성을 검증합니다.

## 5. 🚪 새 대화창 개설 시 '완벽 인계' 프롬프트 템플릿

새 대화창을 열 때 아래 텍스트를 그대로 복사하여 첫 프롬프트로 입력하면, 새 에이전트가 100% 동일한 컨텍스트로 즉시 작업을 개시합니다:

### A) 일반 단원 (국어·사회·수학·영어) 인계 템플릿
```markdown
🏰 [공부방 전담 대화창] 단원 콘텐츠 제작 작업을 진행합니다.
- 사전 확인 문서: kids-school-main/docs/unit_production_pipeline.md 및 kids-school-main/docs/{과목}_spec.md
- 이번 작업 대상: [예: 민수 5-2 사회 2단원 / 민수 5-2 수학 분수의 곱셈 등]
- 입력 소스: 노트북LM에서 추출한 단원 텍스트 (아래 첨부)

위 인계 규격에 맞춰 1) 5분 퀘스트 문제 팩, 2) 단원 동화 스토리북, 3) 과목방 파트 연동을 표준 프로토콜대로 제작해줘.
```

### B) 🔬 과학 단원 (5대 가상실험실 + NotebookLM 실험연계 탐구보고서) 전용 인계 템플릿
```markdown
🔬 [과학 단원 표준 제작] science-unit-builder 스킬과 kids-school-main/docs/science_spec.md 규격에 맞춰 과학 단원을 제작/고도화합니다.
- 참조 레퍼런스: 3단원 『열과 우리 생활』(SCIENCE_LAB_REPORT_3_DATA 및 science_u3_engine.js)과 100% 동일한 구조로 진행할 것.
- 이번 작업 대상: 초등 [5-2] 과학 [4]단원 『[단원명]』
- 입력 소스: 아래 붙여넣은 NotebookLM 실험연계 학습 보고서

[필수 작업 지시]
1) [탭 1 실험연계 탐구 노트]: 핵심 개념/도구 비교표(conceptTables 2~3종) + 교과서 핵심 실험 상세 분석(summaryDoc, SVG 그래프·안전수칙·가상실험실 바로가기 포함) + 첨단과학 심화 탐구 박스(specialDeepDive) 구성
2) [탭 2 참여형 탐구 & 서술형 미션 6종]: 단순 용어 빈칸 맞추기 금지! 채점기준(30%/30%/40%)이 연동된 서술형 문장 조립 빌더 2문항(q1, q5) + 실험 추론/오개념 객관식 2문항(q2, q4) + 섞인 실험 과정 1~4단계 직접 조립기(q3) + 인터랙티브 별점 체크리스트(q6) 구성
3) [검증]: 작업 후 `python -X utf8 scripts/verify_science_unit.py --unit 4` 실행하여 전 항목 PASS 확인 후 배포할 것.
```
