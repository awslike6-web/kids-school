## 2. 교과 범위

- 2-2 「6. 규칙 찾기」: 무늬에서 색깔과 모양의 규칙(두 가지가 따로 반복), 시계 방향으로 한 칸씩 도는 무늬 → 쌓은 모양에서 규칙(쌓기나무가 몇 개씩 늘어나는지) → 덧셈표에서 규칙(→ 1씩·↓ 1씩·↘ 2씩 커지고 ↙ 모두 같음) → 곱셈표에서 규칙(가로줄마다 몇씩 커짐, 3 × 7 = 7 × 3) → 생활에서 규칙(달력: → 1씩·↓ 7씩, 같은 요일은 7일마다, 자리 번호: → 1씩·↓ 한 줄 자리 수만큼).
- **말은 하나로만**: 「규칙」, 수는 「○씩 커져요」, 개수 변화는 「○개씩 늘어나요」, 「→ 오른쪽」·「↓ 아래」·「↘ 오른쪽 아래」·「↙ 왼쪽 아래」, 「시계 방향」, 「쌓기나무」, 「덧셈표」·「곱셈표」, 표의 「가로줄」·「세로줄」(자리 표만 「가 줄」·「나 줄」), 곱셈은 「곱한 값」(「곱」 단독 금지), 「이번 달」. 「견줘요」·「이달」 같은 말은 쓰지 않는다.
- 수의 크기: 덧셈표 칸 값 0~18(두 수 0~9), 곱셈표 2~9단 · 1~9, 달력 1~31, 자리 번호 1~24, 빙고 답 1~81.
- **소리**: 화면 글을 그대로 읽되 이모지(변이 선택자 `U+FE0F`까지)는 읽는 글에서 지운다. 화살표 → 방향 말(→ 「오른쪽」, ↓ 「아래」, ↘ 「오른쪽 아래」, ↙ 「왼쪽 아래」), `×` → 「곱하기」, `★` → 「별」, `□ 칸` → 「빈칸」(「빈칸 칸」이 되지 않게 묶어서 먼저), 남은 `□` → 「빈칸」. `fact`가 있으면 `speak = fact + '. ' + question`(fact가 「요」로 끝나면 마침표를 붙여 쉬게 함). 숫자 뒤 조사는 숫자를 읽는 소리 받침으로(`josaNum`: 7 → 칠 → 「과」, 3 → 삼 → 「과」, 2 → 이 → 「와」). 이모지 무늬 계단 카드는 이모지를 이름으로 푼 읽는 글을 따로 둔다.

### 3-1. 그리기 부품 `RuleDraw` (`js/rule_find-draw.js`, 새 파일)

모두 보는 그림(6관 타일 판만 누름). 360px 화면 카드 안쪽 폭을 **300px**로 잡고 모든 그림이 줄바꿈 없이 한 줄에 들어가야 한다.

- `row(items, { blank })` → `el` — **무늬 줄**: 칸 8~9개 한 줄(줄바꿈 없음, 칸 폭 = 300 ÷ 칸 수, 최소 32px — 9칸 × 33px), 칸 하나 = 이모지 하나(26px 이상), `blank` 번호 칸은 `□`(점선 테두리).
- `stackSeries(list, { last })` → `el` — **쌓기나무 앞모습 여러 개**: `list` = 모양마다 기둥 높이 배열(왼쪽부터, 예 `[1]`, `[2,1]`, `[3,1,1]`), 정육면체 한 개 = 22px 정사각형(윗면·옆면 그늘로 입체 느낌, CSS만), 아래 정렬, 모양 사이 `→`(16px), 맨 뒤에 `last`(`'?'` 상자 하나, 없으면 생략). 모양 4개 + `?`까지 한 줄 300px 안(기둥 합 10개 × 22 + 화살표 4 × 16 + `?` 22 = 306 → 정육면체 20px까지 줄임). 모양 아래 「첫째」·「둘째」… 작은 글.
- `numTable({ op: '+'|'×', rows, cols, star, blanks, marks, arrow })` → `el` — **덧셈표·곱셈표**: 왼쪽 위 칸 `+` 또는 `×`, 첫 가로줄 `cols`, 첫 세로줄 `rows`, 안 칸 = 행 값 op 열 값. 4 × 4(머리 포함 5칸, 칸 52px 이하·44px 이상, 300px 안). `star` = `[r, c]` 칸은 `★`(굵은 테두리, 값 숨김), `blanks` = `[[r, c]]` 칸은 `□`(값 숨김), `marks` = `[[r, c]]` 칸은 노란 칠, `arrow`가 있으면 칠한 첫 칸에서 끝 칸 쪽으로 작은 화살표 배지(`→`·`↓`·`↘`·`↙`).
- `seats({ rowNames, perRow, blank, marks })` → `el` — **자리 번호 표**: 줄 이름(`가`·`나`·`다`·`라`) × 한 줄 자리 수 `perRow`(5~6), 칸 = 자리 번호(가 줄 1부터 이어서), `blank` 칸 `□`, `marks` 노란 칠. 머리 포함 7칸 × 40px = 280px.
- `tileBoard({ rows, cols, cells, blanks, palette, onPick })` → `{ el, select(i), fill(i), lock() }` — **6관 타일 판**: 칸 48px(5칸 = 240px), `blanks` 칸은 빈칸(누르면 그 빈칸을 고름), **지금 고른 빈칸은 굵은 테두리로 늘 하나 켜져 있음**(처음엔 첫 빈칸), 아래 팔레트 버튼 3개(56px) — 팔레트를 누르면 `onPick(지금 빈칸, 타일)`. 맞으면 화면이 `fill(i)`하고 다음 남은 빈칸을 자동으로 고름.

| 퀴즈 배틀 | 단원 정리 | 노션 CURRICULUM_DB `학년=2-2 · 단원 "6. 규칙 찾기"` 탐구퀴즈 12제 | |

- 🪜 계단 카드(1학년 규칙 받침, 질문은 이모지 대신 이름으로 써서 그대로 읽힘):
  - 1관 「되풀이되는 마디」: "똑같이 되풀이되는 부분을 찾으면 다음을 알 수 있어요." 질문 "사과, 바나나, 사과, 바나나, 사과 다음은?" (바나나 / 사과 / 포도).
  - 2관 「하나씩 더」: "앞 모양보다 몇 개 많은지 세어 봐요." 질문 "1개, 2개, 3개 다음은?" (4개 / 3개 / 5개).
  - 3관 「덧셈표 읽기」: "가로줄 수와 세로줄 수를 더한 값을 써요." 질문 "가로줄이 3, 세로줄이 4면?" (7 / 12 / 34).
- **오개념 힌트** (20자 안팎): `repeat-last`(「되풀이되는 마디를 찾아요」), `unit-shift`·`other-item`(「마디를 하나씩 짚어요」), `turn-back`(「시계 방향으로 돌아요」), `color-wrong`(「색깔 규칙도 봐요」), `shape-wrong`(「모양 규칙도 봐요」), `step-plus`·`second-count`(「앞 모양보다 몇 개 많은지 봐요」), `same-as-last`(「한 번 더 늘어나요」), `count-slip`(「다시 세어 봐요」), `dir-mix`(「칠한 칸끼리 차례대로 봐요」), `step-one`(「↘ 방향은 2씩 커져요」), `next-dan`·`prev-dan`(「칠한 수의 차이를 봐요」), `add-instead`(「곱셈표는 곱해요」), `next-cell`(「가로줄과 세로줄을 다시 봐요」), `swap-slip`(「두 수 자리만 바꿔요」), `count-cells`(「칠한 수끼리 빼 봐요」), `one-week-short`·`one-week-more`(「1주일씩 세어 가요」), `row-as-one`(「아래로는 한 줄만큼 커져요」).

## 5. 순수 계산 모듈 `RuleFindCore` (`js/rule_find-core.js`, DOM 없음, 시험 대상)

- `randInt`, `josa(word, pair)`, `josaNum(n, pair)`(숫자 읽는 소리의 받침: 0 영·1 일·3 삼·6 육·7 칠·8 팔·10 십은 받침 있음, 2 이·4 사·5 오·9 구는 없음 — 두 자리 이상은 끝 자리, 끝이 0이면 십), `speakText(text)`(§2 소리 규칙).

## 9. 설계 검토 기록 (2026-11-27)

카본(medium) 14건·네온(medium) 15건, 겹친 것이 많아 모두 반영(네온의 「무늬를 SVG 도형으로」는 이모지 칸을 32px 이상으로 키우는 것으로 대신).
- 오답이 정답과 같아짐: 반 바퀴 무늬(시계·반대 방향 같음) 뺌, 쌓기 `first-count`(a = d인 규칙이 대부분) → 둘째 모양 개수, `cal-week` 고정 오답 → 정답 ± 7, `mul-swap` a = b 뺌, 덧셈·곱셈표 2 + 2 = 2 × 2 겹침 → 그 보기 빼고 ± 1.
- 찍기 틈: `add-dir` 질문 글을 네 방향 같게, `mul-step` 단 이름을 말하지 않음, `mul-swap` 오답에 `a + b`(같은 두 수가 든 다른 식), 빙고 답을 단위 없는 수로 통일.
- 무늬 규칙이 흐려짐: 마디 × 2칸 이상, 마디 안 이모지 서로 다르게, 두 가지 규칙 무늬는 모양 2 · 색 3(6칸마다 한 바퀴).
- 화면: ★ 그리기 넣음, 무늬 줄·쌓기나무·자리 표 300px 한 줄(정육면체 20~22px, 자리 5~6), 다섯째 모양 문제는 넷째까지 그림, 달력 칠한 칸이 줄을 넘지 않게, 자리 빈칸은 나 줄부터, 타일 빈칸은 볼 칸이 있는 자리만·힌트 모드별, 팔레트 늘 3개·지금 빈칸 자동 선택(3번 누르기).
