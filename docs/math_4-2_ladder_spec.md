# 🪜 4-2 분수·소수 사다리 탐험관 설계 명세 (math_4-2_ladder_spec.md)

> 상태: **설계 확정본 (2026-11-24)** · 아르곤·네온 설계 검토 반영(§10), 사용자 결정 "많이 풀며 익숙해지기"(§3-0) 반영. 구현 1~3단계(계산 부품·분수 화면·소수 화면)와 퀴즈 자료 완료 2026-11-24. 남은 것: 노션 등록(§9-5).
> 상위 명세: [`math_spec.md`](math_spec.md) · 공용 틀: [`CORE_CATALOG.md`](../kids/core/CORE_CATALOG.md) 「수학 단원 탐험관 공용 틀 `MathExplorer`」 · 학습자: [`minsu_learning_profile.md`](minsu_learning_profile.md)

## 1. 왜 만드나

- 민수는 5학년이지만 실제 수준은 3~4학년이다. 학교에서 배운 5-2 「분수의 곱셈」·「소수의 곱셈」 바로 아래 계단인 **4학년 2학기 분수·소수 단원이 수학방에 하나도 없다.**
- 3학년 계단(`fractions_decimals.html`: 단위분수·진분수·가분수·대분수 카드, 0.1 수직선)과 5학년 계단(`fractions_multiplication.html`, `decimal_multiplication.html`)은 있다. 이번 두 탐험관이 그 사이를 잇는다.

```
3학년  fractions_decimals.html (가분수·대분수, 0.1)
  ⬆
4-2   ① fraction_add.html  분수의 덧셈과 뺄셈      ← 이번
      ② decimal_add.html   소수의 덧셈과 뺄셈      ← 이번
  ⬆
(5-1  약분과 통분, 분모가 다른 분수의 덧셈·뺄셈)   ← 아직 빈칸 (범위 밖, §8)
  ⬆
5-2   fractions_multiplication.html · decimal_multiplication.html
```

## 2. 교과 근거와 한계

- **수학은 교과서 사진 없이 만든다** (사용자 결정 2026-11-24). 4학년 2학기 성취기준과 단원 흐름을 따르고, 5-2 탐험관처럼 쪽수를 적지 않는다.
- 4학년 범위를 지킨다.
  - 분수: **분모가 같은** 분수의 덧셈·뺄셈만. **약분하지 않는다**(6/8은 6/8 그대로. 약분은 5-1). 계산 결과가 가분수이면 대분수로, 분수 부분이 0이면 자연수로 쓴다.
  - 소수: 소수 두 자리·세 자리 수 읽고 쓰기, 크기 비교, 소수 사이 관계(10배·100배, 10분의 1·100분의 1), 소수 두 자리까지의 덧셈·뺄셈(자연수 − 소수 포함). **계산 결과의 소수점 아래 끝자리 0은 지운다**(1.60 → 1.6).
- **풀이 방법은 하나씩만**: 대분수 뺄셈의 받아내림은 "자연수 1을 분모만큼 조각내기" 한 가지로만 가르친다. "가분수로 바꿔 빼기"는 화면·퀴즈 어디에도 내지 않는다(작업 기억 부담·방법 간섭 방지).

## 3. 공통 설계 (두 탐험관 모두)

### 3-0. 많이 풀면서 익숙해지기 (사용자 결정 2026-11-24, 가장 앞선 원칙)

민수는 문제를 많이 접해 익숙해진 뒤에 개념이 천천히 잡힌다. 그래서 **설명보다 풀기가 먼저**이고, 풀 문제가 떨어지지 않게 한다.

- **관은 바로 문제로 시작**한다. 개념 설명(`ui.concept`)은 처음부터 펼치지 않고 접힌 `[💡 왜 그럴까?]` 버튼 안에 둔다. 1-2-3 계산 순서 카드만 늘 보인다(따라 하다 보면 패턴이 몸에 붙음).
- **관 완주는 3문제 한 판**(성공 경험을 빨리 준다). 완주한 뒤에는 `[🔁 한 판 더]` 버튼으로 같은 종류·같은 순서의 새 수 3문제를 **끝없이** 더 풀 수 있다. 한 판 안에서 같은 문제는 다시 나오지 않는다.
- **7관 ⚡ 연습 마당**: 1~6관 문제 종류를 섞은 10문제 한 판(쉬운 종류 → 어려운 종류 순으로 정렬, 수는 무작위). 첫 판을 마치면 관 완주로 센다. 그 뒤로도 판을 계속 새로 만든다. 탐험관은 관 7개 + 퀴즈 배틀이 된다(감싸개 `mxTotal` 7, "7개 관").
- **더 풀기 보상**: `🔁 한 판 더`와 연습 마당 둘째 판부터는, 맞힌 문제 10개마다 💎1, **화면마다 하루 3개까지**(`localStorage` 키 `math_{key}_drill_{학생}_{로컬 YYYY-MM-DD}`에 오늘 받은 개수). 지급은 `grantRewardAndShowUI(1, false, 'math')`. 화면에 "오늘 더 푼 문제 N개 · 💎 N/3"을 작게 보여 준다. 첫 정답만 세고, 오답 뒤에 고른 정답도 센다(에러리스: 결국 스스로 맞힌 것).
- 무한 문제는 순수 계산 모듈의 `makeRound`·`makeMixedRound`가 만든다(§4·§5).

### 3-1. 화면 공통

- **틀**: `MathExplorer.mount({ key, labs, quiz })`를 쓴다. 틀은 **세로 분수 켜기 옵션 하나만** 넓힌다(아래 「표기」). 옵션을 켜지 않은 기존 5-2 화면은 동작이 그대로다.
- **에러리스**: 모든 고르기는 `ui.choiceQuestion`(3지선다, `QuizChoices`로 섞기, 틀리면 고른 보기만 꺼지고 노란 힌트 + 정답 반짝임). 오개념별 힌트는 `hint`를 함수로 넘겨 고른 보기 번호마다 다르게 쓴다. 빨간 X·감점·경고음 없음.
- **칠하기·지우기 조작 (막대·모눈 공통)**
  - 칸을 직접 누르지 않고 아래의 **큰 버튼**(높이 ≥ 44px)으로만 조작한다: 분수 막대 `[＋ 1칸 칠하기]`·`[－ 1칸 지우기]`, 모눈 `[＋ 0.1 (한 줄)]`·`[＋ 0.01 (한 칸)]`.
  - 칸은 왼쪽부터 순서대로 칠해지거나 오른쪽 끝부터 지워진다. **목표에 닿는 순간 버튼이 잠기고** 반짝임 + `fairyPraise`로 그 단계가 끝난다. 목표를 넘거나 모자라게 끝낼 길이 없다.
  - 모눈 `＋0.1` 버튼은 남은 값이 0.1보다 작아지면 꺼지고 "이제 0.01씩 칠해요" 노란 안내가 뜬다.
- **360px 배치 규칙**
  - 분수 막대는 **한 줄에 하나**, 화면 폭 전체(좌우 여백 빼고 약 310px), 높이 ≥ 44px. 분모 3~10.
  - 대분수의 자연수 부분은 눈금 없는 납작한 `[ 1 ]` 통막대 묶음으로 **윗줄(자연수 줄)**에, 눈금 있는 조각 막대는 **아랫줄(분수 줄)**에 한 줄 전체 폭으로 그린다. 두 수를 더하거나 뺄 때도 같은 두 줄 구조를 위아래로 쌓는다.
  - 10×10 모눈은 한 화면에 하나(폭 약 280px, 칸 28px, 직접 누르지 않음). 비교처럼 두 수를 같이 볼 때는 칠해진 읽기 전용 작은 모눈 2개를 **위아래로** 놓는다.
  - 수직선 눈금 글자는 양 끝과 가운데만 쓴다(예: 0.24 · 0.245 · 0.25).
- **세로셈 칸판 (소수 5·6관)**: 칸 44×44px. 지금 채울 칸(소수점·0 채우기·받아올림 표시·각 자리 답)이 노랗게 켜지고, 칸판 바로 아래에 **큰 보기 버튼 3개**(정답 1 + 오개념 2, `choiceQuestion`)가 뜬다. 숫자 키패드는 쓰지 않는다.
- **1-2-3 알고리즘 카드**: 관마다 계산 순서를 번호 카드 2~3장으로 보여 준다(민수는 패턴 기억이 강점). 한 관 안에서는 같은 카드 묶음이 계속 맞는 문제만 낸다. 🔊는 `speakFairyTTS`.
- **🪜 3학년 계단 카드**: §4·§5 표에서 🪜 표시한 관은 `choiceQuestion`의 `onWrong`이 처음 불리면 노란 힌트 밑에 `[🪜 3학년 계단 다시 보기]` 버튼을 붙인다(관마다 한 번 붙이면 계속 남음). 누르면 관 안에 작은 판이 펼쳐져(다른 화면으로 나가지 않음) 3학년 개념 1장 + 쉬운 3지선다 1개를 풀고 접힌다. 보상 없음. 부품은 별도 소형 파일 `js/math_explorer-ladder.js`(`window.MathLadder.attach(hintHost, { title, body, question })`) 하나를 두 화면이 싣는다.
- **계단 이동 링크**: 감싸개 HTML 머리에 "⬇ 3학년 분수와 소수" · "⬆ 5학년 분수의 곱셈(또는 소수의 곱셈)" 링크 두 개. 틀의 완주 창은 건드리지 않는다.
- **표기 — 화면의 모든 분수는 정식 세로 분수** (수학방 약속 [`math_spec.md`](math_spec.md) 「정품 세로 분수, 슬래시 금지」, 사용자 재확인 2026-11-24): 관 그림·질문·**보기 버튼**·노란 힌트·해설·개념 카드·**퀴즈 배틀**까지 분자 위·가로선·분모 아래로 그리고, 대분수는 자연수와 붙여 그린다. 화면에 `3/5`나 "5분의 3" 글자 분수가 보이면 안 된다.
  - **글자 표기 계약**: 코드·노션 자료 안에서는 5분 퀘스트(`quest_engine.js`의 `formatFractions`)와 같은 꼴로 쓴다 — 진분수·가분수 `3/5`, 대분수 `2와 3/5`(받침 있으면 `1과 3/4`). 화면에 그릴 때 세로 분수로 바꾼다. 소수 탐험관의 `1/10`·`1/100`도 같다.
  - **틀 옵션** `mount({ …, fractions: true })`: 켜면 `ui.choiceQuestion`의 질문·보기·힌트·해설, `ui.concept`·`ui.guide`·`ui.hint`, 퀴즈 배틀의 질문·보기·해설이 글자 표기를 세로 분수 HTML(분자·분모 숫자만 들어가는 고정 모양, 그 밖 글자는 그대로 글자)로 그린다. 음성(`say`)에 넘길 때는 `3/5` → "5분의 3", `2와 3/5` → "2와 5분의 3"으로 바꿔 읽는다. 학습일지에 남기는 "고른 글자"는 글자 표기 그대로(`2와 3/5`).
  - `FractionCore.token(f)`가 글자 표기(`2와 3/5`, `3/5`, 자연수 `2`)를 만들고, 보기 `text`는 `token`, 음성은 기존 `label`("2와 5분의 3")을 쓴다.
  - 보기에 긴 식을 넣지 않는다(식은 질문에, 보기는 답만).
- **학습일지(문항기록) 연결**: 관 안의 모든 3지선다(연습·`🔁 한 판 더`·⚡ 연습 마당)를 `LearningLog.question({ subject: '수학', key })`로 기록한다. 키는 생성형 수학 규칙(`docs/learning_record_spec.md` `g:`)대로 **문제 종류**: `g:frac4-<kind>`(예 `g:frac4-mixed-sub-borrow`), `g:dec4-<kind>`. 틀리면 `wrong(고른 보기 글자 표기)`, 맞히면 `done()`(에러리스라 「첫 시도 실패 → 스스로 맞힘」이 기록됨). 칠하기·지우기 조작 단계와 🪜 계단 카드 질문은 기록하지 않는다. 퀴즈 배틀은 틀에 이미 있는 `c:<page_id>` 기록을 그대로 쓴다.
- **보상**: 틀 그대로 — 관 첫 완주 💎1, 7개 관 모두 하루 1회 +5(`math_fracadd_allclear_…`, `math_decadd_allclear_…`), 퀴즈 문항 첫 정답 💎1.
- **음성**: `speakFairyTTS`(안내·카드), `fairyPraise`(정답·목표 도달), `fairyEncourage`(오답), `fairyReward`(완주). 브라우저 음성 직접 호출 금지.
- **문제 만들기**: 관 안의 연습 수는 순수 계산 모듈이 만든다. **관 안 문제 순서는 쉬운 것 → 어려운 것으로 고정**하고 수만 무작위로 바꾼다. 퀴즈 배틀 12제만 노션에서 읽는다.

## 4. ① 분수의 덧셈과 뺄셈 탐험관 (`fraction_add.html`, key `fracadd`)

> 이 절의 "5분의 3" 같은 분수 글자는 명세를 읽기 쉽게 쓴 것이다. 화면 코드·자료에서는 §3-1 「표기」의 글자 표기 계약(`3/5`)으로 쓰고 화면에는 세로 분수로 그린다.

**분수 규칙**: 분모 3~10. 대분수 자연수 부분 1~4. 결과의 분모는 문제와 같다(약분 없음). 관마다 3문제(순서 고정).

| 관 | 배우는 것 | 활동 (문제 순서) | 🪜 |
| :--- | :--- | :--- | :---: |
| 1관 단위분수 세기 | 5분의 3은 5분의 1이 3개 | `＋1칸` 버튼으로 칠할 때마다 "5분의 1이 1개, 2개, 3개"가 올라간다. ①분수 보고 칠하기 ②분수 보고 칠하기 ③칠한 막대 보고 분수 고르기 | ✓ |
| 2관 진분수 더하고 빼기 | 합이 1보다 작은 덧셈, 진분수 뺄셈 | 같은 막대에서 더하기는 이어 칠하기(파랑+초록), 빼기는 지우기. 카드: ①분모는 그대로 ②분자끼리 더하거나 빼요. ①더하기 ②더하기 ③빼기 | |
| 3관 1을 넘는 합 | 합이 가분수 → 대분수 | 막대 1개가 꽉 차면 그 막대가 `[ 1 ]` 통막대로 접혀 윗줄로 올라가고 아랫줄에 새 조각 막대가 생긴다 → 6분의 9 = 1과 6분의 3. ①합이 딱 1(6분의 6 → "자연수 1", 보기는 1 / 6분의 6 / 12분의 6 중 "자연수로 쓰면?") ②③합이 1보다 큰 문제(대분수로 답 고르기) | ✓ |
| 4관 대분수 더하기 | 자연수끼리·분수끼리, 받아올림 | 두 줄 구조. 카드: ①자연수끼리 ②분수끼리 ③분수가 1이 되거나 넘으면 1을 자연수로 옮겨요. ①대분수 + 진분수(받아올림 없음) ②대분수 + 대분수(받아올림 없음) ③대분수 + 대분수(받아올림 있음) | |
| 5관 1을 쪼개서 빼기 | 1 − 분수, 자연수 − 분수 | 카드: ①통막대 `[ 1 ]` 하나를 분모만큼 쪼개요 ②빼는 만큼 지워요. 통막대를 누르면 조각 막대로 쪼개지는 장면(이 관에서 유일하게 막대를 직접 누름, 누를 막대 하나만 켜짐). ①1 − 진분수 ②자연수 − 진분수 ③자연수 − 진분수 | ✓ |
| 6관 대분수 빼기 | 받아내림, 자연수 − 대분수 | 같은 카드: ①분수끼리 뺄 수 있나 보기 ②못 빼면 자연수 1을 쪼개 분수에 보태기 ③자연수끼리·분수끼리 빼기. ①받아내림 없는 대분수 뺄셈 ②받아내림 있는 대분수 뺄셈(3과 5분의 1 − 1과 5분의 3 → 2와 5분의 6 − 1과 5분의 3 = 1과 5분의 3) ③자연수 − 대분수(3 − 1과 5분의 2) | |
| 7관 ⚡ 연습 마당 | 섞어 풀기 | 그림은 간단한 막대 한 장 + 3지선다만(조작 단계 없음). 1~6관 종류 섞어 10문제, 끝없이 새 판(§3-0) | |
| 퀴즈 배틀 | 단원 정리 | 노션 CURRICULUM_DB 탐구퀴즈 12제(3지선다) | |

- 🪜 3학년 계단 카드: 1관 "단위분수"(1을 똑같이 나눈 것 중 하나), 3관 "가분수와 대분수"(`fractions_decimals.html` 2번 카드와 같은 정의), 5관 "1은 몇 분의 몇?"(1 = 4분의 4).
- **오개념 힌트** (고른 보기마다 다른 노란 안내):
  - 분모끼리도 더함(5분의 2 + 5분의 1 → 10분의 3): "막대 칸 수는 그대로 5칸이에요. 칠한 칸만 늘어나요."
  - 받아올림 뒤 분자에서 분모를 안 뺌(1과 4분의 3 + 1과 4분의 2 → 2와 4분의 5): "4분의 5에는 꽉 찬 막대 1개가 숨어 있어요."
  - 자연수 − 분수에서 자연수만 빼고 분수를 붙임(3 − 4분의 1 → 2와 4분의 1): "4분의 1만 지웠더니 남은 조각은 4분의 3이에요."
  - 자연수 − 분수에서 자연수를 안 줄임(3 − 4분의 1 → 3과 4분의 3): "1을 쪼개 썼으니 통막대가 하나 줄었어요."
  - 받아내림에서 분자에 10을 더함(3과 5분의 1 → 2와 5분의 11): "1은 10조각이 아니라 5분의 5, 5조각이에요."
  - 받아내림에서 분자를 거꾸로 뺌(3과 5분의 1 − 1과 5분의 3 → 2와 5분의 2): "5분의 1에서 5분의 3은 뺄 수 없어요. 자연수에서 1을 빌려 와요."

**순수 계산 모듈 `FractionCore`** (`js/fraction_add-core.js`, DOM 없음, 시험 대상)
- 수 모양: `{ w: 자연수, n: 분자, d: 분모 }`. 정규형: `0 ≤ n < d`(가분수는 `toMixed` 전 중간값으로만).
- `toImproper(f)`, `toMixed(f)`(가분수 → 대분수. `n = 0`이면 자연수), `add(a,b)`, `sub(a,b)`(분모가 다르거나 결과가 0 이하면 `throw`), `needsCarry(a,b)`(분자 합 ≥ 분모), `needsBorrow(a,b)`(빼지는 분자 < 빼는 분자), `split(f)`(자연수 1을 분모 조각으로: 3과 5분의 1 → 2와 5분의 6).
- `label(f)`: 음성용 읽기. `w>0,n>0` → "2와 5분의 1", `w>0,n=0` → "2", `w=0,n>0` → "5분의 3", `w=0,n=0`은 만들지 않음(오류).
- `token(f)`: 화면용 글자 표기(§3-1 「표기」). "2와 1/5", "1과 3/4", "2", "3/5". 2단계에서 더한다. `wrongChoices`의 보기에도 `token`을 붙인다.
- `makeProblem(kind, rng)`: kind = 관별 문제 칸(`unit-count`, `add-proper`, `sub-proper`, `sum-one`, `sum-over`, `mixed-add-proper`, `mixed-add`, `mixed-add-carry`, `one-minus`, `whole-minus`, `mixed-sub`, `mixed-sub-borrow`, `whole-minus-mixed`).
  - 결과는 항상 0보다 크다. `add-proper` 합 < 1, `sum-over` 1 < 합 < 2, `sum-one` 합 = 1.
  - 4관·6관 대분수 문제의 결과는 **자연수 부분 ≥ 1, 분수 부분 ≥ 1**(통막대 줄·조각 줄이 둘 다 남게). `mixed-sub-borrow`는 빼지는 자연수 ≥ 2, 분자 서로 다름.
- `wrongChoices(problem)`: 연산·종류별 오개념 생성식에서 보기 2개(위 오개념 목록). 정답과 같거나, 서로 같거나, 0 이하이거나, 분모가 0이 되면 버리고 "분자 ± 1" 보정으로 채운다. 반환값마다 어느 오개념인지 `kind`를 붙여 힌트 문장과 잇는다.
- 문제 모양: `{ kind, op: '+'|'-'|null, a, b, answer }` (`a`·`b`·`answer`는 분수 모양, `unit-count`는 `b = null`, 답은 단위분수 개수 `answer = { w: 0, n: 개수, d }`가 아니라 그대로 `a`).
- **관별 종류 (순서 고정)** `LAB_KINDS`: 1관 `unit-count ×3` · 2관 `add-proper, add-proper, sub-proper` · 3관 `sum-one, sum-over, sum-over` · 4관 `mixed-add-proper, mixed-add, mixed-add-carry` · 5관 `one-minus, whole-minus, whole-minus` · 6관 `mixed-sub, mixed-sub-borrow, whole-minus-mixed`.
- `makeRound(lab, rng)`: `LAB_KINDS[lab]` 순서대로 3문제, 한 판 안 중복 없음. `makeMixedRound(rng, n = 10)`: 1~6관 종류에서 n문제를 뽑아 `LAB_KINDS` 차례(쉬운 것 먼저)로 정렬, 중복 없음, 한 종류가 3번을 넘지 않음. 둘 다 몇 번을 불러도 끝없이 새 판을 만든다.

## 5. ② 소수의 덧셈과 뺄셈 탐험관 (`decimal_add.html`, key `decadd`)

**소수 규칙**: 부동소수 금지 — `{ int, places }` 표기. 소수 둘째 자리까지 계산, 셋째 자리는 읽기·자릿값·비교·소수 사이 관계에만. 관마다 3문제(순서 고정).

| 관 | 배우는 것 | 활동 (문제 순서) | 🪜 |
| :--- | :--- | :--- | :---: |
| 1관 0.01 모눈 | 소수 두 자리 수 | 1을 나타내는 10×10 모눈을 `＋0.1`·`＋0.01` 버튼으로 칠하기 → 0.37 = 0.1이 3개, 0.01이 7개. 이어 읽기 3지선다 "영 점 삼칠 / 영 점 삼십칠 / 삼십칠". ①칠하기 0.37형 ②칠하기 0.05형(중간 0, "영 점 영오") ③칠한 모눈 보고 수 고르기 | ✓ |
| 2관 0.001과 자릿값 | 소수 세 자리 수, 자리 이름 | 수직선 확대는 구간 보기 버튼 3개(예: `[0.2~0.3]`)를 골라 두 번 확대(0.1 칸 → 0.01 칸 → 0.001 칸)해 0.245 찾기. 이어 2.345 숫자 칸 하나가 켜지면 "이 4는 얼마?" 3지선다(0.04 / 0.4 / 4). ①수직선 ②자릿값 ③자릿값 | |
| 3관 크기 비교 | 자리 수가 다른 소수 비교 | 칠해진 읽기 전용 작은 모눈 2개(위아래) → `[끝에 0 붙이기 (0.7 → 0.70)]` 버튼 → 높은 자리부터 비교 3지선다(＞ ＜ =, 순서 고정). ①②자리 수가 많은 쪽이 작은 문제 ③자리 수가 많은 쪽이 큰 문제 | |
| 4관 소수 사이 관계 | 10배·100배, 10분의 1·100분의 1 | 숫자 띠에서 `[⬅ 10분의 1]`·`[10배 ➡]` 화살표 버튼으로 **소수점을** 옮긴다(숫자는 그대로, 소수점만 이동). 일의 자리 앞이 비면 0이 생기고(3 → 0.3), 소수점 뒤가 비면 소수점이 사라진다(0.3 → 3). 5-2 소수의 곱셈 5관과 같은 모양이지만 그림은 이 관에서 그린다. ①10배 ②100분의 1(화살표 두 번) ③1 → 0.1 → 0.01 → 0.001 줄 세우기(`ui.sequence`) | |
| 5관 소수 한 자리 더하기·빼기 | 0.1이 몇 개 | 0.1 막대(10칸, 한 줄 하나)를 버튼으로 칠하고 지운 뒤 세로셈 칸판. 카드: ①소수점을 먼저 맞춰 찍어요 ②오른쪽부터 계산해요 ③소수점을 그대로 내려요. ①받아올림 없는 덧셈 ②받아올림 있는 덧셈(0.6 + 0.8 = 1.4) ③받아내림 있는 뺄셈 | ✓ |
| 6관 자리 맞춰 세로셈 | 자리 수가 다른 덧셈·뺄셈, 자연수 − 소수 | 먼저 "바르게 줄 세운 세로셈은?" 3지선다(소수점 맞춤 / 오른쪽 끝 맞춤 / 왼쪽 끝 맞춤, 그림 보기는 관 안 질문에 그리고 보기 글자는 "가·나·다") → 빈 칸에 0 채우기(1.5 → 1.50) → 칸판 계산. ①1.5 + 0.34형 ②1.5 − 0.34형 ③자연수 − 소수(2 − 0.35, 2 → 2.00) | |
| 7관 ⚡ 연습 마당 | 섞어 풀기 | 식 한 줄(세로셈이면 이미 줄 세운 칸판 그림) + 3지선다만. 1~6관 종류 섞어 10문제, 끝없이 새 판(§3-0) | |
| 퀴즈 배틀 | 단원 정리 | 노션 CURRICULUM_DB 탐구퀴즈 12제(3지선다) | |

- 5·6관 연습 문제는 **결과 끝자리가 0이 되지 않는 수만** 낸다(칸판에서 끝자리 0 지우기로 헷갈리지 않게). "끝자리 0은 지워요(1.60 → 1.6)" 규칙은 6관 마지막에 개념 카드 1장으로만 보여 주고, 퀴즈 배틀 1문항에서 다룬다.
- 🪜 3학년 계단 카드: 1관 "0.1은 10분의 1"(`fractions_decimals.html` 0.1 수직선), 5관 "0.1이 10개면 1".
- 세로셈 칸판은 이 단원 파일에서 그린다. `vertical_math.html`(정수 격자)은 고치지 않는다.
- **오개념 힌트**: 소수점 아래를 자연수처럼 읽기(0.37 → "영 점 삼십칠"), 중간 0 빠뜨리기(0.05 → "영 점 오"), 자리 수가 많으면 크다(0.65 > 0.7), 받아올림을 자리 하나 더로 착각(0.6 + 0.8 → 0.14), 오른쪽 끝 맞추기(1.5 + 0.34 → 0.49), 빈자리 0 안 채우고 내려 쓰기(1.5 − 0.34 → 1.24), 자연수 − 소수에서 소수점 무시(2 − 0.35 → 2.35·0.33).

**순수 계산 모듈 `DecimalAddCore`** (`js/decimal_add-core.js`, DOM 없음, 시험 대상)
- 기존 `DecimalCore`(`decimal_multiplication-core.js`)의 `dec`·`parse`·`format`·`formatRaw`·`compare`를 **불러 쓰기만** 하고, 그 파일은 고치지 않는다(5-2 화면·시험 영향 없음). `decimal_add.html`은 `decimal_multiplication-core.js` → `decimal_add-core.js` 순서로 싣는다.
- `add(a,b)`, `sub(a,b)`(결과 < 0이면 `throw`): 결과는 자리 수를 유지한 값으로 돌려주고, 보여 줄 때 최종 답은 `format`(끝자리 0 지움), 칸판 과정은 `formatRaw`.
- `align(a,b)` → `{ a, b, places, padA, padB }`: 소수점 아래 자리 수를 큰 쪽에 맞춘 두 수와 각자 0을 채운 칸 수. 자연수는 `places = 0`에서 시작(2 → 2.00이면 `padA = 2`).
- `readAloud(d)`: 자연수 부분은 한자어 수 읽기("십이", 0이면 "영"), 소수점은 "점", 소수 부분은 숫자를 하나씩("삼사", 0은 "영"). `formatRaw` 기준이라 0.70은 "영 점 칠영". 예: 12.34 → "십이 점 삼사", 1.05 → "일 점 영오", 0.245 → "영 점 이사오".
- `digitValue(d, place)`: `place` 0 = 일의 자리, 1~3 = 소수 첫째~셋째 자리. 그 자리 숫자의 값을 `{ int, places }`로 돌려준다(2.345, 2 → `{int:4, places:2}` = 0.04).
- `shift(d, k)`: 소수점을 k칸 옮긴 수(k > 0 이면 10^k배). 숫자 띠 그리기용으로 `{ digits, point, leadingZero }`도 함께.
- `makeProblem(kind, rng)` · `wrongChoices(problem)` · `makeRound(lab, rng)` · `makeMixedRound(rng, n = 10)`: 분수 모듈과 같은 규칙(순서 고정 종류, 오개념 보기 2개, 겹침·음수 보정, 오개념 `kind` 표시, 끝없는 새 판).
- **관별 종류 (순서 고정)** `LAB_KINDS`: 1관 `read-2, read-2-zero, read-2` · 2관 `locate-3, digit-value, digit-value` · 3관 `compare-longer-smaller, compare-longer-smaller, compare-longer-larger` · 4관 `shift-up, shift-down-2, shift-chain` · 5관 `add-1-nocarry, add-1-carry, sub-1-borrow` · 6관 `add-mixed-places, sub-mixed-places, whole-minus-decimal`.
- 문제 모양: `{ kind, op, a, b, answer }`. 읽기(`read-*`)는 `answer` = 읽는 글자, 위치·자릿값은 `answer` = 소수, 비교는 `answer` = `'>'|'<'|'='`, 소수점 옮기기는 `{ a, k, answer }`, 줄 세우기는 `answer` = 소수 배열. 덧셈·뺄셈 종류의 결과는 0보다 크고 끝자리가 0이 아니다(§5 위 규칙).

## 7. 검증

- **자동 시험** (노션 미접속):
  - `FractionCore`: 가분수↔대분수 왕복, `label` 네 경우, 덧셈·뺄셈·`split`, 받아올림·받아내림 판정, `sub` 음수 `throw`, 종류별 seed 300개가 §4 범위 안(분모 3~10, 결과 > 0, `add-proper` < 1, `sum-one` = 1, `sum-over` 1~2, 4·6관 결과 자연수 ≥ 1·분수 ≥ 1), 오답 보기 2개가 정답·서로와 겹치지 않고 0 이하·분모 0 없음, 약분된 답을 만들지 않음.
  - `DecimalAddCore`: 0.7 vs 0.65, 1.5 + 0.34 = 1.84, 1.5 − 0.34 = 1.16, 2 − 0.35 = 1.65, 0.6 + 0.8 = 1.4, `align` 0 채우기 칸 수(자연수 포함), `readAloud` 예시 4개, `digitValue`, `shift`의 0 생기고 사라지기, 5·6관 seed 300개 결과 끝자리 0 없음, 3관 문제 종류 비율, 오답 보기 겹침 없음. 기존 `tests/math-explorer-units.test.mjs` 그대로 통과.
  - 감싸개: 스크립트 순서·상대 경로·파일 800줄 미만·`QuizChoices` 가드(`tests/quiz-choices-guard.test.mjs`)·`?v=` 도장.
  - 퀴즈 자료 JSON: 12제, 보기 3개, 정답 번호 범위, 분수는 글자 표기 계약(`3/5`, `2와 3/5`)만 쓰고 "5분의 3" 글자 분수 없음, 해설에 보기 번호 없음, "가분수로 바꿔 빼기" 풀이 문항 없음, 계산 정답 직접 검산.
- **화면**: 쓰기 차단 서버(`guarded_preview_server.py`, 8767)에서 375px 세로로 14개 관을 모두 끝까지 조작해 사진. 틀린 보기를 일부러 눌러 오개념별 노란 힌트·🪜 버튼이 뜨는지, 버튼이 목표에서 잠기는지 확인. 데스크톱 1회.
- **작업 등급**: 화면 = L1-화면, 단원 core·`MathLadder` = 수학 화면 부품(L1, 공통 코어 `kids/core/` 아님), 퀴즈 자료 = L0.
- **노션 (L3, 사용자 승인 필요)**: CURRICULUM_DB 학년 선택지에 `4-2`가 없다(현재 5-1·1-1·5-2·1-2·3-1·4-1). 등록 도구가 새 선택지를 만들게 되므로 퀴즈 등록 전에 사용자 승인을 받는다. 승인·등록 전에는 퀴즈 탭이 틀 규칙대로 "다시 불러오기"만 보여 준다(하드코딩 대체 문제 없음, §8-2 Zero Hardcoding). 관 14개는 노션 없이 모두 동작한다.
- **사용자 승인 (2026-11-24)**: 퀴즈 등록 때 CURRICULUM_DB 학년 선택지에 `4-2`를 추가해도 된다고 승인함. 등록은 공식 도구 `register_curriculum.py`로만 한다.
