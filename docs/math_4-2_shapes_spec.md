## 2. 교과 근거와 한계

- **교과서 사진 없이 만든다**(수학 공통). 4-2 흐름:
  - 2단원 삼각형: 변의 길이에 따라(이등변삼각형·정삼각형), 이등변삼각형의 두 각이 같음, 정삼각형의 세 각 60°, 각의 크기에 따라(예각삼각형·직각삼각형·둔각삼각형), 두 기준으로 분류.
  - 4단원 사각형: 수직·수선, 평행·평행선, 평행선 사이의 거리, 사다리꼴, 평행사변형(마주 보는 변·각이 같음, 이웃한 두 각의 합 180°), 마름모(네 변이 같음, 마주 보는 각이 같음), 직사각형·정사각형, 여러 사각형 사이의 관계.
  - 6단원 다각형: 다각형·정다각형 이름, 대각선(개수).
- **뜻은 한 말로만**(화면·힌트·퀴즈 모두):
  - 이등변삼각형: 두 변의 길이가 같은 삼각형 · 정삼각형: 세 변의 길이가 같은 삼각형
  - 예각삼각형: 세 각이 모두 예각 · 직각삼각형: 한 각이 직각 · 둔각삼각형: 한 각이 둔각
  - 사다리꼴: 평행한 변이 한 쌍이라도 있는 사각형 · 평행사변형: 마주 보는 두 쌍의 변이 서로 평행한 사각형 · 마름모: 네 변의 길이가 모두 같은 사각형
  - 대각선: 서로 이웃하지 않는 두 꼭짓점을 이은 선분
  - 평행선 사이의 거리: 평행선 사이에 그은 수직인 선분의 길이
- **포함 관계는 교과서 정의 그대로**: 정삼각형은 이등변삼각형이다. 평행사변형·마름모·직사각형·정사각형은 모두 사다리꼴이다. 정사각형은 마름모이고 직사각형이다.
- **분류 문제는 답이 하나만 되게 묻는다**: 이름 보기의 오답은 포함 관계로 따져도 늘 틀린 이름이다(평행사변형 그림에 「사다리꼴」, 정다각형 그림에 「n각형」을 오답으로 넣지 않음). 포함 관계 자체를 묻는 5관은 「부를 수 있는 이름」 1개 + 「부를 수 없는 이름」 2개 꼴(§4-1).
- 꼭짓점 이름은 교과서처럼 `ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ`, 변은 `변 ㄱㄴ`, 각은 `각 ㄱㄴㄷ`. 각도는 `60°`.
- 범위 밖(§9): 작도(자·각도기 그리기), 모양 조각 채우기, 다각형 각의 합 공식.

## 3. 공통 설계

5-1 둘레와 넓이 명세 §3을 따른다. 다른 점만.

- 관 7개 + 퀴즈 배틀(`mxTotal` 7), 관마다 3문제 한 판 뒤 `[🔁 한 판 더]` 끝없이, 7관 ⚡ 섞어 풀기 10문제.
- **문제 = 그림 한 장 + 묻는 말 + 3지선다**. 고르기는 기본 한 번. **두 번 고르기는 세 종류만**: `iso-base`(① 두 밑각의 합 → ② 한 밑각), `angle-class`(① 나머지 각 → ② 삼각형 이름), `two-criteria`(① 꼭지각 → ② 이름). 맞힌 값은 그림의 `?` 자리에 써진다(나머지 각이 90°면 그때 직각 표시로 바뀜 — 처음부터 직각 네모를 그리지 않는다).
- **그림은 실제 모양**: 각도는 실제 각도, 적힌 길이는 비율대로(약도). 모든 도형은 볼록(한 각 < 170°). 3관 `par-pairs`·`perp-side`만 모눈 위 정수 좌표(평행·수직을 눈으로 확인할 수 있게, 평행 표시는 그리지 않음).
- 뜻 카드(`MathDrill.algo`)는 그 관의 뜻·성질 1~3줄(5관은 「마름모도 평행사변형이라 이웃한 두 각의 합이 180°」 포함).
- **이름 보기**(삼각형·사각형·다각형 이름, 변 이름)는 세로 1열(`column: true`), 값 보기는 가로 3개.
- 학습일지 `prefix` `tq4`: 한 번 고르기 `g:tq4-<종류>`, 두 번 고르기 `g:tq4-<종류>-a`·`-b`. 퀴즈 배틀은 `c:<page_id>`.
- 계단 이동 링크(375px 한 줄): `⬇ 각도` · `⬇ 평면도형` · `⬆ 넓이`.

### 3-1. 그리기 — `PolyAreaDraw.figure` 확장 (5-1 그림 부품을 같이 씀, 새 파일 없음)

`fig`에 아래 칸을 **선택으로** 더한다. 칸이 없으면 지금과 똑같이 그린다(5-1 화면 변화 없음 — §8에서 브라우저로 5-1 SVG 글자 비교). 새 칸의 모양(CSS)도 그림 부품 스타일 파일 `math_polyarea.css` 한 곳에 둔다(4-2 감싸개는 `math_polyarea.css`도 싣는다, 테마 색은 `math_triquad.css`).
- 좌표: 화면 좌표(y 아래로 증가), `points`는 화면 시계 방향, 볼록 다각형. `points: []`도 허용(3관 `par-dist`처럼 선분만 있는 그림).
- `vertexNames: ['ㄱ', 'ㄴ', …]` — `points[i]`에서 무게중심 반대쪽 0.6칸에 이름(`text.pa-vname`).
- `angles: [{ at: i, text: '70°' | '?', right: bool, mark: 1|2 }]` — `points[i]`의 **안쪽 각**(이웃 두 변 방향의 사이각, 무게중심 쪽)에 호(`path.pa-arc`, 반지름 0.6칸), `right`면 호 대신 작은 네모(`path.pa-right`). 글자(`text.pa-angle`, `'?'`면 `.pa-angle-q`)는 이등분선 위, 꼭짓점에서 `r = min(2.4, max(1.15, 0.62 / sin(각/2)))`칸 — 좁은 각일수록 멀리. `mark` 2면 호 두 겹(같은 크기 각). 화면이 맞힌 뒤 바꿀 때는 `setAngle(svg, i, text, right)`.
- `parallels: [[i, j], …]` — 변 `i`·`j`가 평행: 두 변에서 **같은 방향**을 가리키는 `>` 표시(`path.pa-par`, 쌍마다 1개·2개), 변의 0.35 지점(같은 길이 빗금 `ticks`는 가운데라 겹치지 않음).
- `segments: [{ a, b, text, kind: 'line'|'seg', right }]` — 자유 선분. `kind: 'line'`은 상자 끝까지 늘인 직선(평행선, 꼬리표 없음). `right: true`는 `a` 끝에서 수평선과 이루는 직각 표시(3관 `par-dist`의 평행선은 늘 가로, 수선은 세로). 꼬리표는 선분 가운데 오른쪽 0.3칸.
- `diagonals`(5-1 계약)는 6관에서 정답 뒤 `revealDiagonals(svg, fig, done)`로 0.2초 간격 차례로 그린다(합쳐 1.2초 이내, 문서에서 떨어지면 멈춤).
- 크기: 가로 ≤ 12칸·세로 ≤ 8칸 상자에 맞춤.

- 🪜 계단 카드:
  - 1관 「두 각이 같아요」: 이등변삼각형을 반으로 접으면 같은 두 변이 겹치고 두 밑각도 겹쳐요.
  - 2관 「180°」: 삼각형 세 각의 합은 180°(4-1에서 배움) → 나머지 각 = 180° − 두 각.
  - 3관 「평행선 사이의 거리」: 두 평행선을 잇는 선분 가운데 수직인 선분의 길이가 거리예요. 기울어진 선분은 더 길고, 한 줄에만 닿는 선분은 거리가 아니에요.
  - 4관 「이웃한 두 각 180°」: 평행사변형의 이웃한 두 각을 더하면 180°, 마주 보는 두 각은 같아요.
  - 5관 「사각형 가족」: 사다리꼴 ⊃ 평행사변형 ⊃ 마름모·직사각형 ⊃ 정사각형(상자 그림 한 장).
  - 6관 「한 꼭짓점에서」: 자기 자신과 이웃한 두 꼭짓점에는 대각선을 못 그어요 → 한 꼭짓점에서 (꼭짓점 수 − 3)개.

### 4-1. 문제 종류와 오답 (`mistake` 이름은 코드에서 씀)

- **값 보기**: 오답 2개 = 첫 후보(① 관 핵심 실수) + 해시(`MixCalcCore.mixHash`)로 나머지 중. 정답·서로와 다름, 각도 1°~179°, 길이·개수 1 이상(`par-pairs`만 0쌍 허용). `calc-slip`(각도 ± 10°, 길이 ± 2, 개수 ± 1)은 **보통 후보**이고, 끝까지 모자랄 때만 보정 보기 `fix`. 크기 위치 돌리기(정답 크기 자리 ≤ 75%).
- **이름 보기**: 오답은 **늘 틀린 이름**(포함 관계로 맞는 이름은 오답에 넣지 않는다, 시험으로 대조).

| 종류 | 묻는 것·정답 | 오답 후보 (① 핵심) |
| :--- | :--- | :--- |
| `iso-side` 둘레 | 같은 변 a 둘 + b → `a × 2 + b` | ① `one-same` `a + b` ② `all-same` `a × 3` ③ `wrong-pair` `a + b × 2` |
| `iso-side` 나머지 변 | 둘레 P, 같은 변 a → `P − a × 2` | ① `one-same` `P − a` ② `wrong-pair` `(P − a) ÷ 2`(정수일 때) ③ `calc-slip` |
| `iso-side` 정삼각형 | 한 변 a → `a × 3` / 둘레 P → `P ÷ 3` | ① `iso-two` `a × 2`·`P ÷ 2`(정수일 때) ② `calc-slip` ③ `n-plus` `a × 4` |
| `iso-base` ① | 꼭지각 x → 두 밑각의 합 `180 − x` | ① `same-apex` `x` ② `from-90` `90 − x`(양수일 때) ③ `calc-slip` |
| `iso-base` ② | 한 밑각 `(180 − x) ÷ 2` | ① `half-miss` `180 − x` ② `calc-slip` ③ `same-apex` `x` |
| `iso-apex` | 밑각 y → 꼭지각 `180 − y × 2` | ① `one-base` `180 − y` ② `two-bases` `y × 2` ③ `same-base` `y` |
| `angle-class` ① | 두 각 a, b → 나머지 `180 − a − b` | ① `one-angle` `180 − a` 또는 `180 − b`(해시) ② `sum` `a + b` ③ `calc-slip` |
| `angle-class` ② | 이름(예각·직각·둔각삼각형) | 나머지 두 이름. 힌트는 틀린 이름의 뜻 + 「가장 큰 각을 봐요」 |
| `two-criteria` ① | 밑각 y → 꼭지각(`iso-apex`와 같은 후보) | 같음 |
| `two-criteria` ② | 「이등변삼각형이면서 ○각삼각형」 | 다른 ○각 두 개 |
| `perp-side` | 직각사다리꼴에서 한쪽 끝만 직각인 평행 변(기준) → 수직인 다리 하나 | ① `parallel` 마주 보는 평행 변 ② `slant` 직각이 아닌 다리 |
| `par-pairs` | 사다리꼴 1·평행사변형 2·직사각형 2·육각형(세 쌍) 3·일반 사각형 0·오각형(한 쌍) 1 | {0, 1, 2, 3}쌍 중 정답 밖 둘(① `count-sides` 변의 수 ÷ 2에 가까운 것 먼저) |
| `par-dist` | 수직 선분 d | 선분 셋: 수직 d(직각 표시)·기울어진 c(> d)·그리고 해시로 둘째 기울어진 c′(> d) 또는 한 줄에만 닿는 짧은 선분 e(< d) → ① `slant` c ② `slant` c′ 또는 `not-between` e |
| `quad-name` | 평행 표시 한 쌍 → 사다리꼴 / 두 쌍(직각 없음, 이웃 변 길이 다름) → 평행사변형 / 없음 → 사다리꼴이 아닌 사각형 | 한 쌍: 평행사변형·마름모 / 두 쌍: 직사각형·마름모 / 없음: 사다리꼴·평행사변형 |
| `para-angle` | 한 각 x → 이웃한 각 `180 − x`(반) 또는 마주 보는 각 `x`(반) | 이웃: ① `same` `x` ② `from-90` `|90 − x|` ③ `calc-slip` / 마주: ① `neighbor` `180 − x` ② `calc-slip` ③ `from-90` |
| `para-side` | 두 변 a, b → `(a + b) × 2` | ① `half` `a + b` ② `four` `a × 4` ③ `area` `a × b` |
| `rhom-angle` | `para-angle`과 같음(마름모 그림, 네 변 빗금) | 같음 |
| `rhom-side` | 마름모·정사각형 한 변 a → `a × 4` / 둘레 P → `P ÷ 4` | ① `side-two` `a × 2`·`P ÷ 2` ② `n-miss` `a × 3`·`P − 4` ③ `calc-slip` |
| `quad-rel` | 직사각형 → 평행사변형·사다리꼴 / 마름모 → 평행사변형·사다리꼴 / 평행사변형 → 사다리꼴 (정답은 그 가운데 하나) | 그 도형이 될 수 없는 이름 둘: 직사각형 → 마름모·정사각형, 마름모 → 직사각형·정사각형, 평행사변형 → 직사각형·마름모·정사각형 중 둘 |
| `poly-name` | 변 n개(n 5~9) → 「n각형」, 정다각형 그림이면 「정n각형」 | 보통 그림: ① `n-off` (n ± 1)각형 ② `regular` 정n각형 / 정다각형 그림: ① `n-off` 정(n − 1)각형 ② 정(n + 1)각형 |
| `diag-one` | n 4~8 → `n − 3` | ① `with-neighbors` `n − 1` ② `n-minus-2` `n − 2` |
| `diag-count` | n 4~6 → 2·5·9 | ① `double` `n × (n − 3)` ② `one-vertex` `n − 3` ③ `calc-slip` |

- 힌트(뜻 카드의 말 그대로): `one-same` "이등변삼각형은 같은 길이의 변이 2개예요." · `all-same` "세 변이 모두 같은 건 정삼각형이에요." · `iso-two` "정삼각형은 세 변이 모두 같아요." · `wrong-pair` "어느 두 변이 같은지 빗금을 봐요." · `same-apex` "꼭지각이 아니라 두 밑각을 구해요." · `half-miss` "두 밑각이 나눠 가지니 ÷ 2를 해요." · `from-90`·`sum`·`one-angle`·`one-base` "삼각형 세 각의 합은 180°예요. 아는 각을 모두 빼요." · `two-bases` "180°에서 두 밑각을 빼요." · `same-base` "꼭지각을 구해요." · `parallel` "평행한 변은 만나지 않아요. 수직은 직각으로 만나요." · `slant`(3관) "기울어진 선분은 거리가 아니에요. 수직인 선분의 길이가 거리예요." · `not-between` "두 평행선을 모두 잇는 선분이어야 해요." · `count-sides` "모눈을 따라 같은 방향인 변끼리 짝지어 봐요." · `same` "이웃한 두 각을 더하면 180°예요." · `neighbor` "마주 보는 두 각은 크기가 같아요." · `half` "둘레는 네 변을 모두 더해요." · `four` "두 변의 길이가 달라요." · `area` "곱하면 넓이예요." · `side-two`·`n-miss` "네 변의 길이가 모두 같아요." · `n-off` "변의 수를 다시 세어 봐요." · `regular` "변의 길이와 각의 크기가 모두 같아야 정다각형이에요." · `with-neighbors`·`n-minus-2` "자기 자신과 이웃한 두 꼭짓점에는 대각선을 못 그어요." · `double` "한 대각선을 두 꼭짓점에서 두 번 셌어요. ÷ 2를 해요." · `one-vertex` "모든 꼭짓점에서 그어 봐요." · `calc-slip` "다시 계산해 봐요."
- 이름 보기 오답 힌트는 틀린 이름의 뜻 한 줄(예: 「둔각삼각형은 한 각이 둔각이에요. 가장 큰 각을 봐요.」).

## 5. 수 규칙

- 각도는 5° 단위, 그림의 실제 각도와 같다. **삼각형 각 하나 ≥ 30°**(글자가 들어갈 자리), 사각형 각 40°~140°.
- `iso-side`: a 3~12, b 2~12, a ≠ b, b < 2a, 둘레 ≤ 40. 정삼각형 a 2~13. 세 꼴(둘레·나머지 변·정삼각형) 고르게.
- `iso-base`: 꼭지각 x 30°~120°(60°·90° 제외), (180 − x) 짝수. `iso-apex`: 밑각 y 30°~75°(60° 제외). 그림 방향(꼭지각 위·아래·옆) 셋을 `key`에 넣어 풀 20개 이상.
- `angle-class`: 예각·직각·둔각이 1/3씩, 두 각 5° 단위, 나머지 각 ≥ 30°. 직각삼각형은 나머지 각이 90°인 문제와 적힌 각이 90°인 문제 반반.
- `two-criteria`: 이등변 + 예각(꼭지각 < 90°, 60° 아님)·직각(꼭지각 90°)·둔각(꼭지각 > 90°).
- `perp-side`: 모눈 정수 좌표 직각사다리꼴(아랫변 5~9, 윗변 2~(아랫변 − 2), 높이 3~6), 좌우·위아래 뒤집기, 꼭짓점 이름 시작 자리 돌리기.
- `par-pairs`: 모눈 정수 좌표 틀 6가지(사다리꼴·평행사변형·직사각형·세 쌍 육각형·일반 사각형·한 쌍 오각형) × 뒤집기·크기.
- `par-dist`: 가로 평행선 사이 거리 d 3~6, 기울어진 선분 c·c′ = d + 1 ~ 10(서로 다름, 가로 이동은 √(c² − d²) 실수 좌표 — 적힌 길이 = 그림 길이), 짧은 선분 e 1~(d − 1).
- `para-angle`·`rhom-angle`: x 40°~140°, x ≠ 90°.
- `para-side`: a 3~12, b 2~12, a ≠ b, 긴 변 ≤ 짧은 변 × 2.5(너무 가는 그림 방지; 넓이 값 = 둘레가 되는 조합은 그 후보만 버림). `rhom-side`: a 2~15.
- `poly-name`: n 5~9, 보통 다각형과 정다각형 반반. `diag-one`: n 4~8. `diag-count`: n 4~6, 모양(정다각형·보통) × 돌리기.
- **풀 크기**: 서로 다른 문제(`key` = 수 + 그림 방향·모양) — 수가 여럿인 종류 20개 이상, 모양 종류(`perp-side`·`par-pairs`·`quad-name`·`quad-rel`·`poly-name`·`diag-one`·`diag-count`) 10개 이상. 한 판 안 중복 없음(6관 ②③은 같은 n 피함).

## 6. 순수 계산 모듈 `TriQuadCore` (`js/tri_quad-core.js`, DOM 없음, 시험 대상)

- `makeProblem(kind, rng, opt)` → `{ kind, unit('2'|'4'|'6'), fig, steps: [{ ask, answerText, value, choiceKind: 'value'|'name', reveal: { angle: i, text, right } | null }](1~2개), cardLines, key }`. `opt.mixed`면 7관 꼴(한 번 고르기, `angle-class`는 세 각을 다 적음). 값 보기 `'70°'`·`'24 cm'`·`'2쌍'`·`'9개'`, 이름 보기는 글자.
- `wrongChoices(p, stepIndex)` → `[{ token, mistake }]` 2개(정답·서로와 다름, 이름 보기는 늘 틀린 이름). `hintFor(p, mistake)`.
- `makeRound(lab, rng)`, `makeMixedRound(rng, 10)`(한 종류 ≤ 2, 단원마다 ≥ 2), `LAB_KINDS`, `MIXED_KINDS`, `KIND_ORDER`, `poolOf(kind)`, `FAMILY`(사각형 포함 관계 표 — 시험이 이름 보기를 이 표로 대조).
- 그림 좌표: 삼각형은 세 각과 밑변 길이로 좌표를 만들어 상자에 맞춤. 사각형·다각형은 종류별 틀. 해시는 `MixCalcCore.mixHash`(먼저 싣는다).

### 6-1. 퀴즈 배틀 여러 단원 (`math_explorer-quiz.js` 작은 확장, 구현 끝)

- `MathExplorerQuiz.create({ unit: ['2. 삼각형', '4. 사각형', '6. 다각형'] })`처럼 **배열도 받는다**. 배열이면 기존 `and` 조건 안의 한 원소로 `{ or: [단원 equals …] }`(학년·과목·구역 조건은 그대로). 글자 하나면 지금과 똑같다. 제목 번호를 세 단원에 걸쳐 Q01~Q12로 매겨 제목 차례 = 단원 차례.

## 8. 검증

- **자동 시험**:
  - 그림 정합: 종류마다 seed 300개 — 삼각형 세 각의 실제 크기 = 문제 각(± 0.5°), 적힌 길이 비율 = 실제 비율(± 2%, `par-dist`는 길이 그대로), `parallels` 쌍은 실제로 평행(기울기 차 < 0.5°), `right` 표시 각은 실제 90°, 모든 각 < 170°(볼록), 정다각형은 변·각이 모두 같음, 상자 안, `points` 시계 방향, `?` 각에는 처음부터 `right`가 없음.
  - 정답을 시험이 따로 계산(세 각의 합 180°, 이웃한 각 180°, 대각선 수 = 실제로 그은 대각선 수, 평행 쌍 수 = 좌표로 센 평행 쌍 수, 수직인 변 = 좌표로 찾은 수직 변).
  - 오답: 2개, 정답·서로와 다름, 범위(각도 1°~179°, 개수 0 이상), 힌트 있음, 보정 보기 ≤ 10%, 관 핵심 실수 ≥ 70%(값 종류), 크기 위치 ≤ 75%(값 종류), **이름 보기 오답은 `FAMILY` 표로 늘 틀림**.
  - 풀 크기, `makeRound`(6관 ②③ 같은 n 없음)·`makeMixedRound`(단원마다 ≥ 2) 계약.
  - `MathExplorerQuiz.buildQueryBody`: 글자 → 지금과 같은 몸통, 배열 → `and` 안 `or`(구현·시험 끝).
  - 감싸개·대문 카드, 퀴즈 JSON 3개(단원 글자, Q01~Q12 번호가 단원 차례).
- **브라우저 한 번 검사(쓰기 차단 서버)**: 5-1 둘레와 넓이 전 종류 seed 몇 개의 SVG 글자를 확장 전·후 비교(같아야 함), 4-2 종류마다 seed 100개를 그려 글자 상자(`getBBox`)끼리·글자와 선이 겹치지 않는지 잰다.
- **화면**: 375px로 7개 관 끝까지, 5-1 둘레와 넓이 화면 다시 한 번, 데스크톱 1회.
- **작업 등급**: L1(화면·단원 부품·공용 퀴즈 틀 작은 확장), 퀴즈 자료 L0, 노션 등록은 사용자 승인 뒤.

- 반영: 이름 보기 오답이 포함 관계로 맞는 이름이 되던 것(평행사변형 그림의 「사다리꼴」, 정다각형 그림의 「n각형」) → 늘 틀린 이름만; `par-dist`는 세 수로 만들 수 없고 정답이 늘 가장 작음 → 가로 이동 실수 좌표, 한 줄에만 닿는 짧은 선분을 섞어 크기 자리 돌림; 범위 밖으로 늘 버려지던 `from-360` 삭제, `calc-slip`은 보통 후보로; `iso-base` 두 번째 고르기가 같은 값 다시 고르기 → 「두 밑각의 합 → 한 밑각」, `para-angle`은 한 번; 60°·90° 경계에서 정답 = 오답 → 제외·후보 보강(`one-angle` 둘, `two-bases`, `(P − a) ÷ 2`); 정삼각형·정사각형 문제 추가(1관 `iso-side`, 5관 `rhom-side`), `quad-rel`은 사다리꼴·정사각형 그림 제외; §3·§4·§4-1 두 번 고르기 표 통일, 7관 목록 정리·단원마다 2문제 이상; 좁은 각 글자 → 각 30° 이상·각이 좁을수록 글자를 멀리, 평행 표시는 0.35 지점; `perp-side`는 직각사다리꼴로 수직 변이 하나, `par-pairs`·`perp-side`는 모눈 정수 좌표(평행 표시 없이 판별), 0쌍 허용; `?` 각에 처음부터 직각 표시 금지(7관 `angle-class`는 세 각 다 적음); 그림 확장 계약(화면 좌표·볼록·빈 `points`·선분 직각 기준·평행 표시 같은 방향·대각선 차례 그리기); 6관은 「한 꼭짓점에서」 + 전체(n 4~6)로 낮춤; 퀴즈 단원 배열은 `and` 안 `or`, 번호 Q01~Q12를 단원 차례로; 그림 칸 CSS는 `math_polyarea.css` 한 곳; 이름 보기 세로 1열.
- 반영 안 함·바꿔 반영: 네온 13의 「5-1 SVG 스냅샷·글자 겹침 자동 시험」은 node에 DOM이 없어 브라우저 한 번 검사(§8)로 바꿈.
- 구현 중 고친 것: 계산 부품 초안 983줄 → 좌표·원료(`tri_quad-geo.js`)와 문제·오답(`tri_quad-core.js`) 둘로; 길이 꼬리표를 꼭짓점 번호로 적던 것 → 좌표로; 아주 뾰족한 이등변삼각형(각 < 30°) → 원료에서 뺌; 「한 쌍 오각형」 틀이 실제로는 평행 0쌍 → 좌표 교체; 보통 다각형의 한 각이 170° 넘음 → 흔들기를 줄여 다시; 한 꼭짓점 대각선 문제의 정답이 늘 가장 작음 → n − 4 후보; 브라우저 글자 상자 검사(종류마다 100~200개)에서 겹침 두 곳 — 평행선 사이 거리의 짧은 선분·수직 선분 꼬리표, 평행사변형 둘레의 짧은 변 꼬리표와 꼭짓점 이름 → 짧은·수직 선분을 붙이지 않고, 꼭짓점 이름은 변·각·꼭짓점을 묻는 문제에만; 두 변 차이가 큰 평행사변형이 너무 가늘게 그려짐 → 비율 2.5배 이내. `PolyAreaDraw` 확장 뒤 5-1 그림 15종 SVG 지문이 확장 전과 같음을 확인.
