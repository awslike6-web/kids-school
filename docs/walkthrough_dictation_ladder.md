# 받아쓰기 훈련소 3단계 사다리 화면 검증 (2026-11-04)

화면 흐름은 노션 쓰기 차단 서버(`scripts/guarded_preview_server.py`)에서 민서 프로필로 확인했다. 실제 노션 쓰기는 아래 「실제 노션 왕복」 1건만 했다.

## 확인한 흐름
- 회차 카드: `시작 전` → `⭐ 1 / 3단계` → `🏅 완성`으로 바뀐다. 예전 카드의 잘못된 번호 범위(`2회 (2. …)`가 211~220번으로 계산됨)는 뺐다.
- 1단계 4회: 함정 블록(`만낫다.`)을 고르면 틀린 어절을 표시하고, 그 문장이 대기열 맨 뒤로 가며(10→11개), 정답 10개를 맞히면 판이 끝난다. `fairyPraise` 10회, `fairyEncourage` 1회, `fairyReward('finish')` 1회 호출.
- 2단계: 함정 글자(`낫`)가 섞이고, 띄어쓰기를 빼면 "띄어쓰기를 살펴봐요"가 나온다. 정답 전체 보기 후 맞히면 통과 수가 늘지 않고 뒤에서 한 번 더 푼다.
- 이어 하기: 2단계에서 2문장 통과 후 창을 닫고 다시 들어오면 남은 8문장만 나온다.
- 3단계 타자: 마침표를 빼면 "문장 부호를 살펴봐요"가 나온다. 3번 이상 틀린 문장은 자석 입력과 초성 힌트로 내려온다.
- 3단계 공책: 정답 공개 → `다르게 썼어요`는 맨 뒤로, `똑같이 썼어요`는 통과로 처리된다.
- 완성 뒤 연습: 통과 수는 늘지만 저장된 진도는 바뀌지 않는다.
- 전송 내용(차단 서버에서 가로챔): `{"properties":{"숙련도":{"rich_text":[{"text":{"content":"2|2026-11-04|2026-11-04"}}]}}}`. `달성` 칸은 보내지 않는다.

## 모바일 375×812
- 가로 스크롤 없음(문서 폭 375, 본문 335). 블록·자석·확인 버튼이 모두 터치 가능한 크기로 줄바꿈되고, 세로 스크롤은 팝업 안에서 동작한다.
- 콘솔 오류 없음(자동 새로고침 때 뜨는 브라우저 `beforeunload` 안내 1건 제외).

## 실제 노션 왕복 (사용자 승인, 1건)
- 대상: 민서 1-2 1회 `꽃이 활짝 피었습니다.` (시험 전 `숙련도` 빈칸, `달성` 해제). Node에서 `notion-api-client.js`의 실제 `updateVocaMasteryProgress`를 호출했다.
