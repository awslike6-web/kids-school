# 🧮 초등 수학 멀티버스 개념탐험·격자세로셈·동화도서관 통합 명세서 (math_spec.md)

## 1. 개요 및 설계 철학
* **문서 목적**: 초등학교 5학년 2학기(수의 범위와 어림, 분수의 곱셈, 합동과 대칭) 민수와 1학년 2학기(100까지의 수, 덧셈과 뺄셈) 민서의 교과 수학 개념 정복 및 연산 훈련을 총괄하는 **수학방 단일 원천(SSOT) 명세서**.
* **핵심 철학**:
  1. **실패 없는 수학 (Errorless Math Learning - 절대 원칙)**:
     - 수학에 대한 불안감과 오답 스트레스가 큰 아이들을 위해 붉은 X 표시, 감점, 타이머 독촉을 전면 배제한다.
     - 오답 입력 시 즉각적인 경고 대신 '힌트 수직선', '자리수 가이드 블록', '친절한 요정 코코 음성'을 제공하여 스스로 정답을 찾아 100% 성공 경험으로 마무리한다.
  2. **자녀별 맞춤 이원화 (Dual Profile Integration)**:
     - **👦 민수 (초5)**: docs/minsu_learning_profile.md 준수. 실질 인지 난이도를 3~4학년 수준으로 맞춤 조절. 추상적인 계산 공식 강요를 지양하고, **수직선 점 찍기(이상·이하·초과·미만)**, **색상별 격자 자리수 가이드(세로셈)**, **3지선다 콕 터치(공식 정의)**를 적용한다 (마인크래프트 네온 테마, 보상 💎).
     - **👧 민서 (초1)**: 100까지의 수 10개씩 묶어세기 시각화, 10 가르기와 모으기, 캔디/슬라임 파스텔 테마(보상 🍬).
  3. **수학 개념의 시각적 인터랙티브 모델링**:
     - 눈으로만 읽는 교과서를 넘어, 수직선 범위를 드래그하고, 올림·버림·반올림 저울을 기울이며, 사칙연산 격자판을 채우는 직관적 물리 인터랙션을 제공한다.

## 3. 세부 모듈 상세 명세

### 1) 📚 단원 동화 도서관 (math_storybook_library.html)
- **전용 서가 룸 신설**: 과목 로비와 분리된 독립 도서관 룸으로, 단원별 동화책을 한곳에서 체계적으로 관리.
- **학년/단원 필터 탭**:
  - 🌟 전체 보기, 🎒 1~2학년 기초 (민서), 🚀 3~4학년 핵심, 👑 5~6학년 심화 (민수)
- **1호 도서 사양**:
  - **도서명**: [5-2 1단원 1권] 민수와 민서의 수학 멀티버스 대모험
  - **학습 주제**: 수의 범위(이상·이하·초과·미만)와 어림하기(올림·버림·반올림)
  - **분량**: 총 11장 (표지 1장 + 성문 2장 + 롤러코스터 2장 + 포션제작소 2장 + 어림마을 2장 + 귀환 2장)
  - **음성**: edge-tts (ko-KR-SunHiNeural) 11트랙 완비 (kids/assets/audio/storybook/math_multiverse/math_multiverse_p1.mp3 ~ p11.mp3)
  - **뷰어 연동**: 전용 래퍼(math_multiverse_storybook.html) 및 범용 공용 뷰어(common/storybook_viewer.html?subject=math&book=story_math_multiverse) 듀얼 지원.

#### 2) 🎯 5학년 2학기 1단원 : 수의 범위와 어림하기 (ranges_estimation.html)
- **인터랙티브 수직선 탐험기**:
  - 이상(●) / 이하(●) : 경계값을 포함하는 채워진 동그라미 수직선 표현.
  - 초과(○) / 미만(○) : 경계값을 포함하지 않는 뚫린 동그라미 수직선 표현.
  - 마우스 드래그 및 터치로 수의 범위를 늘리고 줄이며 포함되는 자연수 목록을 실시간 출력.
- **황금 포션 어림하기 시뮬레이터**:
  - 올림(구하려는 자리 아래를 올려서 0으로), 버림(버려서 0으로), 반올림(0~4 버림, 5~9 올림)의 원리를 눈금 실린더 포션 주입 인터랙션으로 체득.
- **교과서 원본 연동**: 상단 📖 교과서 원본 보기 모달을 통해 실제 학교 교과서 페이지를 1:1로 대조 열람 가능.

### 3) 🧱 실전 문제 트레이닝 센터 (vertical_math.html 등)
- **사칙연산 격자 세로셈 무한 연산판**:
  - 받아올림/받아내림 자리수 맞춤 격자 가이드라인(일의 자리, 십의 자리, 백의 자리 컬러 블록).
  - 민수의 시지각 협응을 돕는 큼직한 숫자 키패드 및 에러리스 즉시 교정.
- **공식 & 개념 정의 퀴즈 배틀**:
  - 주관식 서술형 타이핑을 강요하지 않고 **'3지선다 콕 터치'**로 용어 정의와 성질을 선택.
  - 10문제 풀이 시 2문제당 +1💎/🍬 실시간 지급 + 10문제 완주 보너스(+5💎/🍬, 예습 부스트 시 +7💎/🍬).

### 4) 🧮 민민 연산 멀티 스튜디오 (`math_operator_studio.html`)
- **직접 수식 입력 (Custom Formula Input)**: 두 자리 수(또는 세 자리 수) ÷ 한 자리 수 등 원하는 수식을 직접 입력하거나 추천 프리셋 버튼으로 즉시 소환.
- **4대 다차원 시각화 표현 탭 (Multi-Representation)**:
  - ① **🧱 십진 블록 분배관**: 10개짜리 막대를 먼저 나누어 주고, 남은 막대가 낱개 10개로 **"펑! 💥"** 쪼개져 합쳐지는 시각 애니메이션 (내려쓰기의 본질 체득).
  - ② **📝 단계별 격자 세로셈 튜터**: 몫 올리기 ➔ 곱하기 ➔ 빼기 ➔ 일의 자리 내려쓰기의 전 과정을 한 단계씩 네온 조명하며 에러리스 가이드.
  - ③ **📏 수직선 덜어내기**: 동수누감(뛰어 덜어내기) 횟수로 몫과 나머지를 거리 감각으로 직관화.
  - ④ **🍫 면적/넓이 모델**: 가로 $\times$ 세로 사각형 넓이 분할로 직관적 몫 산출.
- **요정 코코 실시간 음성 구연 해설 (TTS)**: 각 단계마다 나긋나긋한 음성으로 계산 원리와 주의점을 친절하게 설명.
- **사칙연산 확장성**: 나눗셈(집중 특화)을 필두로 덧셈, 뺄셈, 곱셈 엔진 전환 탭 인터페이스 기본 장착.

## 4. 수학 스토리북 제작 표준 프로토콜 (Storybook Generation Protocol)

1. **지문 찌꺼기 100% 제거**: AI(Gems 등) 생성 텍스트의 (이미지: ... 참고), [컷 연출: ...] 등 지문 찌꺼기 영구 제거.
2. **텍스트-오디오-삽화 삼위일체 (Zero Drift)**:
   - 삽화의 상황(예: 키 132cm 민수의 130cm 이상 성문 통과, 키 120cm 민서의 120cm 초과 롤러코스터 탑승 불가와 회전목마 탑승)과 화면 대사, edge-tts 음성이 1글자의 오차도 없이 1:1 일치.
3. **디렉토리 표준**:
   - 도서 데이터: kids/subjects/math/data/story_{식별자}.js
   - 표지 및 본문 삽화: kids/subjects/math/images/{학생}/{학년-학기}/{단원}/multiverse_storybook/
   - 오디오 트랙: kids/assets/audio/storybook/{식별자}/
   - 뷰어 래퍼: kids/subjects/math/{식별자}_storybook.html (75줄 표준 규격)
4. **공용 뷰어 어댑터 경로 표준**:
   - kids/subjects/common/storybook_viewer.html 호출 시 imgBase가 ./로 시작할 경우 ../../로 자동 보정하여 리소스 누락 방지.
