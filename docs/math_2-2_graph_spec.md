## 2. 교과 범위

- 2-2 「5. 표와 그래프」: 자료를 분류해 세기(빠뜨리거나 두 번 세지 않기) → 표로 나타내기(종류별 수·합계) → 자료를 조사하기(누가 무엇을 골랐는지 적은 「조사한 자료」) → 그래프로 나타내기(○·×·/를 **아래에서 위로**(가로 그래프는 **왼쪽에서 오른쪽으로**) **한 칸에 하나씩 빈칸 없이**) → 표와 그래프의 내용 알기(가장 많은·적은 것, 몇 명 더, ○명보다 많은 것) → 조사한 자료·표·그래프 각각 알기 쉬운 것.
- **말은 하나로만**: 「조사한 자료」, 「표」, 「그래프」, 「합계」, 「가로」·「세로」, 「아래부터 빈칸 없이」. 「적어도」·「차이」 같은 말은 쓰지 않는다(「가장 적게」·「몇 명 더 많아요」).
- **수의 크기**: 한 종류 1~6, 종류 3~4가지, **합계 20 이하**(표 읽기에 집중, 네 수 덧셈·받아내림이 무겁지 않게). 7관 빙고 표만 종류 5가지·값 1~9 모두 다름·합계 30 이하. 단위는 주제가 정한다(학생 수 `명`, 물건 `개`).
- **표시**: 그래프 표시는 교과서처럼 ○·×·/. 읽는 글에서 소리 내야 하는 표시는 ○(「동그라미」)뿐이다 — 4관 그리기는 ○만 쓰고, ×·/는 3관 읽기 그래프 그림과 6관 꾸미기(고르는 버튼 그림)에만 나온다(소리로 이름을 말하지 않음).
- **소리**: 화면 글을 그대로 읽되 이모지는 읽는 글에서 뺀다(변이 선택자 `U+FE0F`·`U+200D`까지). `□` → 「빈칸」, ○ → 「동그라미」, 표시 뒤 조사는 바꾼 낱말 받침에 맞춤(「동그라미를」). `fact`가 있는 문제는 `speak = fact + 공백 + question`. 콜론이 들어간 화면 글(「지우: 🍓 딸기」)은 읽는 글을 따로 만든다(「지우는 딸기」).

## 3. 공통 설계 (2-2 시각과 시간과 같음)

- 틀 `MathExplorer.mount`(`rememberTab`, `wishBox`), `MathDrill.ask/rounds/algo/why`, `MathLadder`, `MathBingo`. 보기 순서는 공용 틀이 섞는다(`QuizChoices`). 학습일지 `g:graph2-<종류>`. key `graph2`, 테마 `mx-theme-graph2`(주황·하늘), 몸 클래스 `mx-grade2`.
- 계단 이동 칩: `⬆ 4학년 막대그래프`(bar_line.html) 하나(아래 계단 2-1 분류하기는 아직 없음 — 🪜 계단 카드가 「같은 것끼리 세기」를 받친다).
- **한 화면 높이**: 360×640 화면에서 문제 하나(안내표 + 질문 + 표 또는 그래프 + 버튼)가 스크롤 없이 들어오게, 그래프는 칸 6줄 이하·칸 40px(그래프 높이 ≈ 300px 이하). 표와 그래프를 함께 보여 주는 문제는 없다(4관 그리기만 표 + 그래프, 그래서 4관 그래프는 칸 5~6줄).

### 3-1. 그리기 부품 `TableGraphDraw` (`js/table_graph-draw.js`, 새 파일)

모두 보는 그림(누르는 칸은 `graph`의 `editable`만, 6관은 바깥 버튼이 `add`를 부름).

- `cards(list, { cols })` → `el` — **그림 카드 격자**. `list` = `[{ emoji, label }]`(label은 `사과` 또는 친구 이름 `지우`), 카드 한 장 = 큰 이모지(28px 이상) + 아래 작은 글(이름, 친구 카드면 「지우」 아래 이모지). `cols` 기본 4, 폭 100%(최대 340px), 간격 6px. 카드는 섞인 순서 그대로(종류끼리 모으지 않음). 누를 수 없다.
- `table(t)` → `el` — **표**(교과서 모양 가로 두 줄): 첫 줄 `t.head`(예 `과일`) · 종류 칸 … · (`t.noTotal`이 아니면) `합계`, 둘째 줄 `t.rowHead`(예 `학생 수(명)`) · 수 … · 합계 수. **종류 칸은 이모지 위 · 이름 아래 두 단**(3글자 이름이 한 줄로), 머리 칸 글은 두 줄로 나뉘어도 됨, 글자 13px 이상. `t.blank`(종류 번호 또는 `'total'`)는 그 칸에 `□`(굵은 테두리). 360px에서 6칸(머리 + 종류 4 + 합계, 또는 머리 + 종류 5)이 한 줄. 7관 빙고 표는 `noTotal`(합계 열 없음, 6칸).
- `graph(g)` → `{ el, set(values), get() → values, add(col) → bool, highlight(cols), lock(bool) }` — **○ 그래프**.
  - `g = { orient: 'v'|'h', kinds: [{ emoji, label }], values, rows, mark: '○'|'×'|'/', unit, axisLabel, kindHead, editable: { col, onChange, onHint } }`.
  - `orient 'v'`(세로 그래프): 가로 = 종류(아래쪽에 이모지 위·이름 아래), 세로 = 수(왼쪽에 1 … `rows`, **아래가 1**), 각 기둥에 `values[i]`개 표시를 **아래부터**. 왼쪽 위 구석에 `axisLabel`(예 `(명)`), 왼쪽 아래 구석에 `kindHead`(예 `과일`)를 작게.
  - `orient 'h'`(가로 그래프): 세로 = 종류(왼쪽 칸, 이모지 위·이름 아래 두 단, 폭 56px), 가로 = 수(아래쪽에 1 … `rows`, **왼쪽이 1**), 표시는 **왼쪽부터**. `rows`는 6 이하라 56 + 6 × 40 = 296px로 360px 화면 안.
  - 칸은 정사각형 **40px 이상**(누르는 칸이므로), 표시 글자는 칸 가운데 크게(24px 이상). 격자선은 옅게, 바깥 테두리는 진하게.
  - `editable`이 있으면 그 기둥(`col`) 칸만 누를 수 있다(다른 기둥은 잠김). 규칙: **다음 빈칸(아래/왼쪽에서 첫 빈칸)을 누르면 표시가 생기고**, **맨 끝에 그린 칸을 누르면 지워진다**(되돌리기), 그 밖의 칸을 누르면 그리지 않고 `onHint('gap')`(화면이 「아래부터 빈칸 없이 그려요」·가로면 「왼쪽부터 빈칸 없이 그려요」를 읽음). 바뀔 때마다 `onChange(지금 개수)`. 켜진 기둥의 칸은 `rows`개(4개를 넘음)지만 **기둥 하나만 켜지므로 버튼 수 규칙의 예외**로 둔다. 다음 빈칸은 점선 테두리가 천천히 깜빡인다(`prefers-reduced-motion`이면 깜빡임 없이 점선만).
  - `add(col)`: 그 기둥 다음 빈칸에 표시를 놓으며 살짝 튀는 움직임(0.3초, `prefers-reduced-motion`이면 없음), 칸이 가득 차면 `false`. 6관 투표용.
  - `highlight(cols)`: 그 기둥들을 옅게 칠함(확인 장면·힌트).
- 순수 함수(시험 대상, DOM 없이): `cellFor(orient, col, k, rows)` → `{ x, y }`(표시 k번째(0부터)가 들어갈 격자 칸 좌표, x = 왼쪽부터 칸 번호, y = 위부터 칸 번호 — 세로면 `{ x: col, y: rows - 1 - k }`, 가로면 `{ x: k, y: col }`), `tapResult(count, idx)` → `'add'|'erase'|'gap'`(기둥에 지금 `count`개, 누른 칸 순번 `idx`(0 = 아래/왼쪽 첫 칸): `idx === count` → add, `idx === count - 1` → erase, 그 밖 → gap; 칸이 다 차면 idx = count인 칸은 없음).

## 4. 표와 그래프 탐험관 (`table_graph.html`, key `graph2`)

| 관 | 배우는 것 | 활동 (문제 순서) | 🪜 |
| :--- | :--- | :--- | :---: |
| 1관 📋 세어서 표로 | 분류해 세기, 표, 합계 | ① `count-kind`: 그림 카드 8~10장(물건 주제 `basket`, 종류 3~4가지 섞임, 한 종류 1~5개) + "딸기는 몇 개예요?" (n / n ± 1 `miss-one` / 다른 종류 하나의 수 `other-kind` — 겹치면 n ± 2, 둘 중 하나는 n보다 작게(n ≥ 2일 때)) ② `table-total`: 표(합계 `□`, 종류 3~4가지) + "합계는 몇 명이에요?" (합 / 합 − 한 종류 `skip-one`(아무 종류, 합 ± 1과 겹치지 않는 것) / 합 ± 1 `add-slip`) ③ `table-blank`: 표(한 종류 `□`, 합계 보임) + `fact` 「합계는 ○명이에요」 + "빈칸에 알맞은 수는?"(화면 글은 「□에 알맞은 수는?」) (빈칸 값 / 합계 `total-as-blank` / 절반은 다른 종류 수의 합 `sum-others`, 절반은 빈칸 ± 1 `add-slip` — 정답이 늘 가장 작은 보기가 되지 않게) | ✓ |
| 2관 🔍 조사한 자료 | 누가 무엇을 골랐나 | 친구 카드 7~9장(이름 + 고른 것, 이름은 겹치지 않음, 종류 3가지) + `fact` 「친구들이 좋아하는 동물을 조사했어요」 — 문제마다 새 자료 ① `survey-count`: "강아지를 고른 친구는 몇 명이에요?" (n / n ± 1 `miss-one` / 친구 전체 수 `count-all` — 겹치면 n ± 2) ② `survey-who`: "곰을 고른 친구는 누구예요?"(자료에 **딱 한 명만 고른 종류가 꼭 하나**, 나머지 두 종류는 2명 이상; 보기는 이름 3개: 정답 / 다른 것을 고른 친구 둘 `wrong-friend`) ③ `survey-most`: "가장 많은 친구가 고른 동물은?"(가장 많은 것 하나뿐, 보기 이름 3개 세로: 정답 / 가장 적은 것 `most-least-swap` / 나머지 `other-kind`) | |
| 3관 📊 그래프 읽기 | ○ 그래프 읽기 | 그래프(세로·가로 반반, 표시 ○·×·/ 무작위, 칸 5~6줄) ① `graph-count`: "포도를 좋아하는 학생은 몇 명이에요?" (n / n + 1 `next-cell`(n < rows일 때만) · n − 1 `miss-one`(n ≥ 2일 때만) · 칸 수 `rows-as-count`(rows ≠ n일 때만) 중 둘, 될 수 있으면 하나는 n보다 크고 하나는 작게) ② `graph-most`: "가장 많은 학생이 좋아하는 과일은?" 또는 "가장 적은 …"(반반, **가장 많은 것과 가장 적은 것이 둘 다 하나뿐**, 보기 이름 3개 세로: 정답 / 반대 `most-least-swap` / 나머지 하나 `other-kind`) ③ `graph-diff`: "사과는 귤보다 몇 명 더 많아요?"(A > B) (A − B / A + B `add-instead` / 절반은 A `read-one`, 절반은 (A − B) ± 1 `count-slip` — 겹치면 다른 쪽) | ✓ |
| 4관 ✏️ 그래프 그리기 | 표 → 그래프, 빈칸 없이 | ①② `draw-col`: 표(모두 보임) + 그래프(칸 5~6줄, 다른 기둥은 다 그려짐, 한 기둥만 빈칸, 목표 개수 1~5, 표시 ○) + `fact` 「표를 보고 그래프를 완성해요」 + "딸기 칸에 ○를 그려요"(①은 세로, ②는 가로) → 칸을 눌러 그리고 `[✔ 다 됐어요]` → 맞으면 칭찬, 적으면 「○ 2개 더 그려요」, 많으면 「○ 1개 지워요」(끝 칸을 누르면 지워짐) 안내 후 계속. 빈칸 사이를 누르면 「아래부터 빈칸 없이 그려요」 ③ `graph-rows`: 표만 + `fact` 「표를 보고 세로 그래프를 그리려고 해요」 + "세로 칸은 가장 적게 몇 칸 필요해요?" (가장 큰 수 / 합계 `total-rows` / 종류 수 `kinds-rows` — 겹치면 가장 큰 수 − 1(1 이상) 또는 + 1) | ✓ |
| 5관 💡 표와 그래프 알기 | 내용 알기, 알기 쉬운 것 | ① `more-than`: 그래프만 + "3명보다 많은 과일은 몇 가지예요?"(기준 = 자료에 있는 수 중 **가장 큰 수보다 작은 것**, 그 수와 같은 종류가 하나 이상 → 정답 1가지 이상) (k / 같은 것까지 센 수 `include-equal` / k ≥ 2면 k − 1 `miss-one`, 아니면 종류 수 전체 `count-all` — 겹치면 k + 1) ② `which-easy`: 그림 없이 세 문제 중 하나, 보기 셋 고정 `조사한 자료`·`표`·`그래프` — "누가 무엇을 골랐는지 알 수 있는 것은?" → 조사한 자료 · "모두 몇 명인지 알기 쉬운 것은?" → 표 · "가장 많은 것을 한눈에 알기 쉬운 것은?" → 그래프. 오답 힌트는 고른 것마다 따로(§4 끝) ③ `most-least-diff`: 그래프만 + `fact` 「가장 많은 것과 가장 적은 것을 견주어요」 + "가장 많은 쪽이 몇 명 더 많아요?" (차 / 가장 큰 수 `read-one` / 차 ± 1 `count-slip`(차 ≥ 2면 − 1)) | |
| 6관 🗳️ 우리 반 투표 | 그래프 만들기 놀이 | 투표 주제(종류 3~4가지) → 먼저 그릴 표시 고르기 `[○]`·`[×]`·`[/]`(꾸미기, 그 판 내내 쓰임) → 빈 세로 그래프(칸 **6줄 고정**) 아래 종류 버튼 3~4개 → 친구 투표 카드가 한 장씩(화면 「지우: 🍓 딸기」, 읽기 「지우는 딸기」) → **같은 종류** 버튼을 누르면 그 기둥에 `add`, 다른 종류를 누르면 「딸기 칸에 그려요」 안내·카드 그대로. 투표 **6~8장**(한 종류 5표 이하), 다 끝나면 질문 하나 "가장 많이 뽑힌 것은?"(가장 많은 것 하나뿐) → 정답이면 투표 도장 +1. 누르는 횟수 = 표시 1 + 투표 6~8 + 질문 1 = 10번 이하. 끝없이 새 투표, 3판 맞히면 관 완료, 6판마다 🍬 | |
| 7관 🎯 표 빙고 | 섞어 풀기 | 빙고판 위에 **표 하나**(종류 5가지 주제, 값 1~9 모두 다름, 합계 30 이하, 합계 열 없음)를 띄우고, 부르는 문제는 그 표를 본다: "사탕은 몇 명?" 5문제 + "합계는 몇 명?" 1문제 + 3문제는 "사탕은 과자보다 몇 명 더 많아요?"(차)·"사탕과 과자는 모두 몇 명?"(두 종류 합) 섞어서. 9문제 답(수)이 모두 다름(맞지 않으면 차·합 문제를 다시 뽑고, 그래도 안 되면 표를 새로). 한 판 더 하면 새 표 | |
| 퀴즈 배틀 | 단원 정리 | 노션 CURRICULUM_DB `학년=2-2 · 단원 "5. 표와 그래프"` 탐구퀴즈 12제 | |

- 🪜 계단 카드(2-1 분류하기 받침):
  - 1관 「같은 것끼리 세기」: "하나씩 손가락으로 짚으며 세면 빠뜨리지 않아요." 질문 "🍎🍌🍎🍎🍌 사과는 몇 개?" (3개 / 2개 / 5개).
  - 3관 「○ 하나는 한 명」: "그래프의 ○ 하나는 한 명이에요. ○ 수를 세면 돼요." 질문 "○가 4개 있으면 몇 명?" (4명 / 5명 / 1명).
  - 4관 「아래부터 차곡차곡」: "그래프는 아래 칸부터 빈칸 없이 하나씩 그려요." 질문 "○를 처음 그리는 칸은?" (맨 아래 칸 / 맨 위 칸 / 가운데 칸).
- 4관 ①②·6관은 문제 상자 안 버튼이 그래프 칸(켜진 기둥 하나) 또는 종류 버튼 + 버튼 최대 4개.
- **오개념 힌트** (20자 안팎): `miss-one`(「손가락으로 짚으며 세어요」), `other-kind`(「다른 것을 셌어요」), `skip-one`(「빠뜨린 것이 있어요」), `add-slip`(「다시 더해 봐요」), `total-as-blank`, `sum-others`(「합계에서 빼요」), `count-all`, `wrong-friend`, `next-cell`(「○ 수만 세어요」), `rows-as-count`(「칸 수가 아니라 ○ 수」), `most-least-swap`, `add-instead`(「더 많은 만큼은 빼요」), `read-one`, `count-slip`, `total-rows`, `kinds-rows`(「가장 큰 수만큼 칸이 필요해요」), `include-equal`(「같은 것은 많은 게 아니에요」). `which-easy`는 고른 오답마다: 표를 골랐는데 정답이 조사한 자료 → 「표로는 누가 골랐는지 몰라요」, 그래프 → 조사한 자료 → 「그래프로는 누가 골랐는지 몰라요」, 조사한 자료 → 표 → 「하나하나 다 세어야 해요」, 그래프 → 표 → 「표에 합계가 있어요」, 조사한 자료 → 그래프 → 「하나하나 세어야 해요」, 표 → 그래프 → 「그래프는 높이로 바로 보여요」.

## 5. 순수 계산 모듈 `TableGraphCore` (`js/table_graph-core.js`, DOM 없음, 시험 대상)

- `randInt`, `josa(word, pair)`(받침에 맞는 조사, pair `은/는`·`이/가`·`을/를`·`과/와`), `markWord(mark)`(○ → 동그라미, × → 엑스, / → 빗금), `speakText(text)`(이모지·변이 선택자 지우기, `□` → 빈칸, 「○를」 → 「동그라미를」(조사를 바꾼 낱말에 맞춤), 빈칸 두 개 정리).
- `TOPICS` — 주제 표, 주제마다 `{ id, word, unit, kinds: [{ emoji, label }] }`, 종류 이름 1~3글자, `word`는 받침 있는 말(질문 틀 「좋아하는 과일은?」의 조사 `은` 고정이 맞게), 같은 소리 이름 없음(과일 배·탈것 배 같은 것):
  - `fruit` 과일 · 명 · 🍎사과 🍌바나나 🍊귤 🍇포도 🍓딸기
  - `animal` 동물 · 명 · 🐶강아지 🐱고양이 🐰토끼 🐻곰 🦊여우
  - `color` 색깔 · 명 · 🔴빨강 🟡노랑 🔵파랑 🟢초록 🟣보라
  - `sport` 운동 · 명 · ⚽축구 🏊수영 ⚾야구 🏀농구 🥋태권도
  - `snack` 간식 · 명 · 🍬사탕 🍪과자 🍩도넛 🍫초코 🍰케이크
  - `season` 계절 · 명 · 🌸봄 ☀️여름 🍁가을 ⛄겨울 (4가지 — 빙고에서는 안 씀)
  - 카드 세기(1관 ①) 물건 주제 `basket` 바구니 속 과일 · 과일 · 개(🍎🍌🍊🍇🍓). 2관 조사 자료는 `animal`·`fruit`·`sport`·`snack` 중 하나(질문 「…을 고른 친구는」의 조사는 `josa`로).
  - 질문 틀(모든 주제 같음): 「좋아하는 학생」(3·5관), 「고른 친구」(2관), 「가장 많은 학생이 좋아하는 {word}은?」.
- `FRIENDS` — 친구 이름 12개(2글자): 지우·하준·서연·도윤·수아·시우·하은·은우·지호·예린·준서·다온. **아이 이름 금지.** 한 자료 안에서 겹치지 않게 뽑는다.
- `makeData(rng, opts)` → `{ topic, kinds, values, total }`. `opts`: `kinds`(3|4|5), `min`·`max`(값 범위), `distinct`(값 모두 다름), `uniqueMax`·`uniqueMin`(가장 큰·작은 값이 하나뿐), `exactOne`(값이 1인 종류가 딱 하나), `minTotal`·`maxTotal`. 종류는 주제에서 무작위로 골라 원래 순서대로. 기본은 값 1~6·합계 20 이하.
- `makeProblem(kind, rng)` → `{ kind, question, fact, speak, answerText, data, …종류별 값 }`. 종류별 값: `count-kind {cards, target}`(cards = 섞인 `[{emoji,label}]`) · `table-total {data}` · `table-blank {data, blank}` · `survey-count {survey, target}`(survey = `[{ name, kind }]`) · `survey-who {survey, target}` · `survey-most {survey}` · `graph-count {data, orient, mark, rows, target}` · `graph-most {data, orient, mark, rows, most: true|false}` · `graph-diff {data, orient, mark, rows, a, b}` · `draw-col {data, orient, mark: '○', rows, col}` · `graph-rows {data}` · `more-than {data, orient, mark, rows, base}` · `which-easy {tool: 'survey'|'table'|'graph'}` · `most-least-diff {data, orient, mark, rows}`.
- 그래프 칸 수 `rows` = 5 또는 6, 가장 큰 값 이상(값은 6 이하라 늘 됨). 6관은 6.
- 답 글: 수는 `4명`·`3개`·`2가지`·`5칸`, 이름은 종류 이름(`딸기`)·친구 이름(`지우`)·도구 이름(`조사한 자료`·`표`·`그래프`).
- `wrongChoices(p)` → `[{ text, mistake }]` 정확히 2개, 정답·서로와 글자가 다름, 수는 1 이상(0명·0칸·0가지 없음). 모자라면 정답 ± 1·± 2(1 이상)로 채움. 이름 보기는 그 자료에 있는 이름만. 수 보기는 **정답이 늘 가장 작은(또는 가장 큰) 보기가 되지 않도록** 위 표의 절반 규칙을 따른다.
- `hintFor(p, mistake, pickedText)` → 힌트 글(위 오개념 표, `which-easy`는 고른 도구에 따라).
- `LAB_KINDS`: 1관 `count-kind, table-total, table-blank` · 2관 `survey-count, survey-who, survey-most` · 3관 `graph-count, graph-most, graph-diff` · 4관 `draw-col, draw-col, graph-rows`(① 세로·② 가로) · 5관 `more-than, which-easy, most-least-diff`. `makeRound(lab, rng)`(한 판 3문제, 차례대로).
- `drawFeedback(count, target)` → `{ ok, diff, text }`(「○ 2개 더 그려요」·「○ 1개 지워요」·맞으면 ok).
- `makeVote(rng)` → `{ topic, kinds, votes: [{ name, kind }], answer, speakCards }`(투표 6~8장, 종류 3~4가지, 한 종류 5표 이하, 가장 많은 것 하나뿐, 친구 이름 겹치지 않음, `speakCards[i]` = 「지우는 딸기」), `voteFeedback(cardKind, pressedKind)` → `{ ok, text }`(틀리면 「딸기 칸에 그려요」).
- `makeBingo(rng)` → `{ data, problems }`(data = 5가지 주제·값 1~9 모두 다름·합계 30 이하, problems 9개 `{ kind: 'bingo-count'|'bingo-total'|'bingo-diff'|'bingo-pair', call, speak, answerText }`, 답 글자(`5명`) 모두 다름, `call` 「사탕은 몇 명?」·「합계는 몇 명?」·「사탕은 과자보다 몇 명 더 많아요?」·「사탕과 과자는 모두 몇 명?」, 조사는 받침에 맞춤, 25자 이내). 화면은 `MathBingo.render`의 `makeBingo` 콜백 안에서 이 함수를 불러 빙고판 위 표를 새로 그리고 `problems`만 돌려준다(공용 빙고 부품은 고치지 않음).
